### II. ARCHITECTURAL CONTEXT & PROBLEM STATEMENT

Running a bare `tsc` execution compiled `apps/worker/src/index.ts` and
`apps/worker/src/tools.ts` directly into `apps/worker/src/`, creating orphaned
`index.js` and `tools.js` build artifacts.

This causes runtime collision and shadowing:

1. Node.js, Wrangler, and Vitest can resolve the stale `.js` files instead of
   the fresh TypeScript sources.
2. Changes made to `index.ts` or `tools.ts` appear to be ignored because the
   runtime executes the frozen `.js` build files.

To prevent this permanently:

1. Delete all compiled JavaScript artifacts from `apps/worker/src/`.
2. Configure `apps/worker/tsconfig.json` with `"noEmit": true` so that `tsc`
   runs strictly as a type checker and never emits build files alongside source
   code (Wrangler and Vitest bundle on the fly via esbuild).
