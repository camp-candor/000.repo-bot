## TARGET FILES:

### MISSION OBJECTIVE

Enhance `apps/worker/src/routes/slackEvents.ts` so that if an operator pastes a
prompt that begins with `data\directive` or `data/directive` (with or without
leading slashes/quotes), the worker automatically normalizes and wraps it into
`execute [data/directive/.../<file>]` behind the scenes before dispatching to
Jules.

---

### 1. IMPLEMENTATION IN `apps/worker/src/routes/slackEvents.ts`

1. Export a helper function
   `normalizeDirectivePrompt(rawPrompt: string): string`:
   - Strips leading/trailing quotes (`"` or `'`).
   - Checks if it already matches `/^execute\s*\[.+\]$/i`. If so, returns it.
   - Converts backslashes (`\`) to forward slashes (`/`) and removes leading
     `./` or `/`.
   - Checks if the normalized string starts with `data/directive/`.
   - If true, returns `execute [${normalizedPath}]`.
   - Otherwise, returns `rawPrompt`.
2. Apply `normalizeDirectivePrompt` to `promptPart` immediately after splitting
   on `:` in the Slack message handler.

---

### 2. UNIT TESTS IN `apps/worker/test/unit/julesSlackObserver.test.ts`

Add test cases asserting:

1. `data\directive\day-001\000.jules.md` converts to
   `execute [data/directive/day-001/000.jules.md]`.
2. `"data/directive/day-002/001.task.md"` converts to
   `execute [data/directive/day-002/001.task.md]`.
3. `\data\directive\day-003\002.task.md` converts to

4. `execute [data\directive\day-001\000.jules.md]` is not double-wrapped.
5. `bump main version` remains untouched.
