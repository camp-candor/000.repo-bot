### II. ARCHITECTURAL MISSION & REQUIREMENTS

When an operator clicks `[View Commit Diff [GitHub]]` from a
`:: DIRECT WORKSTATION PUSH DETECTED` card in `#ops-bridge`, GitHub opens a
comparison page showing "There isn't anything to compare" because `compareUrl`
resolves to `.../compare/<branch>`, which compares `main` against the branch
rather than displaying the specific commit diff.

1. **Deterministic Commit URL Routing (`apps/worker/src/index.ts`):**
   - In `handleGitHubWebhook` under the `githubEvent === 'push'` listener:
     - Do not rely on `payload.compare` as the button target.
     - Construct the direct, canonical commit URL:
       ```typescript
       const commitUrl = `[https://github.com/$](https://github.com/$){repo}/commit/${headCommitSha}`
       ```
     - Pass `commitUrl` (or `commitUrl` aliased to `compareUrl`) into
       `buildLocalPushCard`.

2. **Card Builder Verification (`apps/worker/src/slackBridge.ts`):**
   - In `LocalPushParams`, ensure `compareUrl` points directly to
     `https://github.com/${repo}/commit/${headCommitSha}` so clicking the button
     always renders the specific file changes and line additions/deletions.
   - Set the button text to `View Commit Diff [GitHub]`.

3. **Unit Test Updates (`apps/worker/test/unit/slackBridge.test.ts`):**
   - Update unit tests in `slackBridge.test.ts` to assert that the action button
     URL in `buildLocalPushCard` matches
     `https://github.com/${repo}/commit/${sha}`.
   - Verify `POST /webhook` for a push event passes the canonical `/commit/`
     link to the Slack payload.
