### II. ARCHITECTURAL REQUIREMENTS

#### 1. The 13-State Lifecycle Model

Model the complete task lifecycle using 13 formal states:

- `PENDING`: Task registered in ledger, awaiting allocation.

- `CLAIMED`: Execution lease reserved; epoch assigned.

- `RUNNING`: Remote worker actively compiling or rendering.

- `VERIFYING`: Automated checks running against PR or candidate artifacts.

- `SCOPE_PASSED`: Blast radius and file allowlists verified.

- `AWAITING_APPROVAL`: High-risk path requiring architect cryptographic
  sign-off.

- `MERGING`: CAS squash-merge and ref update actively executing.

- `MERGED`: Terminal success; ref update settled on remote trunk.

- `RETRYING`: Non-fatal failure within retry threshold; counter incremented.

- `ROLLING_BACK`: Invariant breach or watchdog expiration; executing
  compensating actions.

- `ROLLED_BACK`: Compensating actions settled; awaiting requeue or quarantine.

- `DLQ`: Dead-Letter Queue; maximum attempts exhausted or fatal security breach.

- `HALTED`: Non-destructive system pause via kill-switch or budget ceiling.

#### 2. Authenticated Actor Union

Derive actor authorization from a closed discriminated union:

```typescript
export type AuthenticatedActor =
  | { type: 'SYSTEM_INTERNAL' }
  | { type: 'REMOTE_WORKER'; workerId: string; epoch: number }
  | { type: 'AUDIT_ENGINE' }
  | { type: 'LEAD_ARCHITECT'; userId: string }
```

#### 3. State Engine Core (`src/fsm/transitions.ts`)

- Define `FSMContext` capturing task metadata (`taskId`, `currentEpoch`,
  `attemptCount`, `maxAttempts`, `isHighRiskPath`, `auditedHeadSha`,
  `candidateHeadSha`, `scopeCheckPassed`, `qualityCheckPassed`, `branchName`,
  `targetRepo`, `baseCommitSha`, `rollbackClass`, `rollbackReason`).

- Implement `evaluateTransition(currentState, event, actor, ctx, payload?)`:

1. **Terminal No-Op Check:** If `['MERGED', 'DLQ'].includes(currentState)` and
   `event !== 'OPERATOR_REQUEUE'`, return
   `{ nextState: currentState, isNoop: true }`.

2. **Worker Epoch Fencing:** If `actor.type === 'REMOTE_WORKER'`, assert
   `actor.epoch === ctx.currentEpoch`. Mismatch throws
   `Error('STALE_WORKER_EPOCH: ...')`.

3. **Rule Indexing & Matching:** Match rules on `(currentState, event)`. Filter
   by `authorizedActorTypes.includes(actor.type)` and `guard(ctx, payload)`.

4. **Guard Totality:** If zero rules match, throw `ILLEGAL_FSM_TRANSITION` or
   `UNAUTHORIZED_OR_GUARD_FAILED`. If multiple rules match, throw
   `AMBIGUOUS_TRANSITION_ERROR`.

5. **Context Patching:** Apply `producePatch(ctx, payload)` if defined and
   return `{ nextState, contextPatch }`.

#### 4. Vitest Property & Invariant Battery (`test/unit/fsmTransitions.test.ts`)

- Verify low-risk straight-through path
  (`PENDING -> CLAIMED -> RUNNING -> VERIFYING -> SCOPE_PASSED -> MERGING -> MERGED`).

- Verify high-risk human approval gate
  (`SCOPE_PASSED -> AWAITING_APPROVAL -> MERGING -> MERGED`).

- Verify PR head drift invalidation: `NEW_HEAD_PUSHED` while in `SCOPE_PASSED`
  or `AWAITING_APPROVAL` resets back to `VERIFYING` and unsets
  `scopeCheckPassed`, `qualityCheckPassed`, and `auditedHeadSha`.

- Verify emergency halts: `KILL_SWITCH_TRIP`, `BUDGET_EXHAUSTED`, and
  `OPERATOR_CANCEL` transition all 7 active non-terminal states to `HALTED`.

- Verify retry ceiling partitioning: `WATCHDOG_EXPIRE` transitions to `RETRYING`
  when `attemptCount < maxAttempts` and `ROLLING_BACK` when
  `attemptCount >= maxAttempts`.

- Verify terminal no-ops: late events on `MERGED` or `DLQ` return
  `{ isNoop: true }` without throwing.

- Verify pseudo-random fuzzer: 10,000 deterministic pseudo-random event
  sequences asserting that the engine never enters an undefined state or throws
  unhandled errors.

      to: 'HALTED' as TaskState,
      authorizedActorTypes: [
        'SYSTEM_INTERNAL' as const,
        'LEAD_ARCHITECT' as const,
      ],
    },
    {
      from: state,
      event: 'BUDGET_EXHAUSTED' as FSMEvent,
      to: 'HALTED' as TaskState,
      authorizedActorTypes: ['SYSTEM_INTERNAL' as const],
    },
    {
      from: state,
      event: 'OPERATOR_CANCEL' as FSMEvent,
      to: 'HALTED' as TaskState,
      authorizedActorTypes: ['LEAD_ARCHITECT' as const],
    },
  ]),
  {
    from: 'HALTED',
    event: 'OPERATOR_RESUME',
    to: 'PENDING',
    authorizedActorTypes: ['LEAD_ARCHITECT'],
    producePatch: (ctx) => ({
      attemptCount: ctx.attemptCount + 1,
      branchName: `spec/${ctx.taskId.toLowerCase()}-attempt${ctx.attemptCount + 1}`,
      candidateHeadSha: undefined,
      auditedHeadSha: undefined,
      scopeCheckPassed: false,
      qualityCheckPassed: false,
      rollbackClass: undefined,
      rollbackReason: undefined,
    }),
  },
]

const TRANSITION_MAP = new Map<string, TransitionRule[]>()
for (const rule of TRANSITION_TABLE) {
  const key = `${rule.from}:${rule.event}`
  const existing = TRANSITION_MAP.get(key) || []
  existing.push(rule)
  TRANSITION_MAP.set(key, existing)
}

export function evaluateTransition(
  currentState: TaskState,
  event: FSMEvent,
  actor: AuthenticatedActor,
  ctx: FSMContext,
  payload?: any,
): TransitionResult {
  // 1. Idempotent No-Op on Terminal States (Precedes worker epoch checks)
  if (
    ['MERGED', 'DLQ'].includes(currentState) &&
    event !== 'OPERATOR_REQUEUE'
  ) {
    return { nextState: currentState, isNoop: true }
  }

  // 2. Worker Epoch Fencing: Enforce epoch integrity for remote workers
  if (actor.type === 'REMOTE_WORKER') {
    if (actor.epoch !== ctx.currentEpoch) {
      throw new Error(
        `STALE_WORKER_EPOCH: Worker epoch (${actor.epoch}) does not match current epoch (${ctx.currentEpoch}).`,
      )
    }
  }

  const rules = TRANSITION_MAP.get(`${currentState}:${event}`)
  if (!rules || rules.length === 0) {
    throw new Error(
      `ILLEGAL_FSM_TRANSITION: Event '${event}' is not permitted from state '${currentState}'.`,
    )
  }

  const matchingRules = rules.filter((r) => {
    const actorAuthorized = r.authorizedActorTypes.includes(actor.type)
    const guardPassed = r.guard ? r.guard(ctx, payload) : true
    return actorAuthorized && guardPassed
  })

  if (matchingRules.length === 0) {
    throw new Error(
      `UNAUTHORIZED_OR_GUARD_FAILED: Transition '${currentState}' via '${event}' rejected for actor '${actor.type}'.`,
    )
  }

  if (matchingRules.length > 1) {
    throw new Error(
      `AMBIGUOUS_TRANSITION_ERROR: Multiple rules matched for '${currentState}' via '${event}'. Guards must partition context.`,
    )
  }

  const selectedRule = matchingRules[0]
  const patch = selectedRule.producePatch
    ? selectedRule.producePatch(ctx, payload)
    : undefined

  return { nextState: selectedRule.to, contextPatch: patch }
}
