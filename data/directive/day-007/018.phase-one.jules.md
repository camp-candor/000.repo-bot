   orphaned alarm will cause the watchdog to fire against completed work and
   create duplicate execution attempts.

7. **SELECTIVE EPOCH FENCING:** The monotonic epoch counter ($N \to N+1$) must

   cancellation, security violation, and retry. The epoch must remain constant
   on promoting events (`SUBMIT_VERIFICATION`, `PASS_QUALITY`, `CONFIRM_MERGE`)
   so that valid in-flight workers retain authority to complete their staged
   commits.

### II. ARCHITECTURAL REQUIREMENTS

#### 1. Formal FSM State Transition Matrix (`apps/worker/src/fsm/transitions.ts`)

- **13 Closed FSM States:** `PENDING`, `CLAIMED`, `RUNNING`, `VERIFYING`,
  `SCOPE_PASSED`, `AWAITING_APPROVAL`, `MERGING`, `MERGED` (terminal),
  `RETRYING`, `ROLLING_BACK`, `ROLLED_BACK`, `DLQ` (terminal), `HALTED`.

- **Transition Events Union:**
- `CLAIM_LEASE`, `ACK_RUNNING`, `SUBMIT_VERIFICATION`, `PASS_SCOPE`,
  `PASS_QUALITY`, `FAIL_QUALITY`, `APPROVE`, `REJECT`, `CONFIRM_MERGE`,
  `WATCHDOG_EXPIRE`, `HALT`, `RESUME`, `RETRY`, `ROLLBACK_COMPLETE`,
  `EXHAUST_RETRIES`.

- **Transition Rules:**
- `PENDING` + `CLAIM_LEASE` $\to$ `CLAIMED`

- `CLAIMED` + `ACK_RUNNING` $\to$ `RUNNING`

- `RUNNING` + `SUBMIT_VERIFICATION` $\to$ `VERIFYING`

- `RUNNING` + `WATCHDOG_EXPIRE` $\to$ `RETRYING` (or `ROLLING_BACK` if attempts
  $\ge$ max)

- `VERIFYING` + `PASS_SCOPE` $\to$ `SCOPE_PASSED`

- `SCOPE_PASSED` + `PASS_QUALITY` $\to$ `MERGING` (or `AWAITING_APPROVAL` if
  high-risk)

- `SCOPE_PASSED` + `FAIL_QUALITY` $\to$ `RETRYING` (or `ROLLING_BACK`)

- `AWAITING_APPROVAL` + `APPROVE` $\to$ `MERGING`

- `AWAITING_APPROVAL` + `REJECT` $\to$ `ROLLING_BACK`

- `MERGING` + `CONFIRM_MERGE` $\to$ `MERGED`

- `RETRYING` + `RETRY` $\to$ `PENDING`

- `RETRYING` + `EXHAUST_RETRIES` $\to$ `DLQ`

- `ROLLING_BACK` + `ROLLBACK_COMPLETE` $\to$ `ROLLED_BACK`

- Any active state + `HALT` $\to$ `HALTED`

- `HALTED` + `RESUME` $\to$ `PENDING`

- **Terminal No-Op Guard:** Events received on terminal states (`MERGED`, `DLQ`,
  `ROLLED_BACK`) must be treated as safe no-ops rather than throwing exceptions,
  preventing webhook replay storms.

- **Event Classification:**
- `isRevokingEvent(event)`: `WATCHDOG_EXPIRE`, `REJECT`, `HALT`,
  `EXHAUST_RETRIES`, `FAIL_QUALITY`.

- `isPromotingEvent(event)`: `SUBMIT_VERIFICATION`, `PASS_SCOPE`,
  `PASS_QUALITY`, `APPROVE`, `CONFIRM_MERGE`.

#### 2. Durable Object In-Memory Temporal Authority (`apps/worker/src/objects/ShotCoordinatorDO.ts`)

- **Boot Barrier Rehydration:** Inside `constructor(ctx, env)`, invoke
  `this.ctx.blockConcurrencyWhile(...)` to load state from NVMe storage into
  local V8 isolate memory. Hydrate:

- `taskId: string`
- `fsmState: TaskState` (default `'PENDING'`)

- `currentEpoch: number` (default `0`)

- `leaseExpiresAt: number` (default `0`)

- `attemptCount: number` (default `0`)

- `maxAttempts: number` (default `3`)

- `activeWorkerId: string | null`

- **Unified State Choke Point (`applyTransition`):** Single-turn atomic storage
  transaction executing:

1. Validate transition legality against `transitions.ts`.

2. Enforce self-transition guard (if `nextState === currentState`, return
   early).

3. Selective epoch fencing: if `isRevokingEvent(event)` or
   `event === 'CLAIM_LEASE'`, increment monotonic epoch: `currentEpoch += 1`.

4. Hardware alarm reconciliation:

- If `nextState === 'RUNNING'`, arm hardware alarm:
  `this.ctx.storage.setAlarm(Date.now() + 30000)`.

- If `currentState === 'RUNNING'` and `nextState !== 'RUNNING'`, unconditionally
  delete alarm: `this.ctx.storage.deleteAlarm()`.

5. Commit updated context to `ctx.storage` and local memory projection.

- **RPC & HTTP Interface:**
- `POST /leases/claim`: Checks state is `PENDING`. Bumps epoch ($N \to N+1$),
  records worker ID, transitions to `CLAIMED`, grants 30-second lease with
  fencing token ($N$).
- `POST /leases/heartbeat`: Receives `{ workerId, epoch }`. Bumps expiration by
  +30 seconds, extends `ctx.storage.setAlarm(Date.now() + 30000)`. If presented
  `epoch !== currentEpoch`, immediately returns `HTTP 409 Conflict`.
- `POST /tasks/complete`: Receives `{ workerId, epoch, payload }`. Evaluates
  fencing token: if `epoch < currentEpoch`, rejects with
  `HTTP 409 Conflict (STALE_EPOCH_ZOMBIE)`. Otherwise, advances state to
  `VERIFYING` and disarms alarm.
- `alarm()` callback: Wakes when 30 seconds elapse without a valid heartbeat
  pulse. Transitions `RUNNING` $\to$ `RETRYING` (or `DLQ` if attempts
  exhausted), bumps epoch ($N \to N+1$) to fence out the disconnected worker,
  and disarms remaining timers.

```typescript
export type TaskState =
  | 'PENDING'
  | 'CLAIMED'
  | 'RUNNING'
  | 'VERIFYING'
  | 'SCOPE_PASSED'
  | 'AWAITING_APPROVAL'
  | 'MERGING'
  | 'MERGED'
  | 'RETRYING'
  | 'ROLLING_BACK'
  | 'ROLLED_BACK'
  | 'DLQ'
  | 'HALTED'

export type TaskEvent =
  | 'CLAIM_LEASE'
  | 'ACK_RUNNING'
  | 'SUBMIT_VERIFICATION'
  | 'PASS_SCOPE'
  | 'PASS_QUALITY'
  | 'FAIL_QUALITY'
  | 'APPROVE'
  | 'REJECT'
  | 'CONFIRM_MERGE'
  | 'WATCHDOG_EXPIRE'
  | 'HALT'
  | 'RESUME'
  | 'RETRY'
  | 'ROLLBACK_COMPLETE'
  | 'EXHAUST_RETRIES'

export interface TransitionContext {
  attemptCount: number
  maxAttempts: number
  isHighRisk?: boolean
}

export interface TransitionResult {
  isValid: boolean
  nextState: TaskState
  isTerminalNoOp: boolean
  error?: string
}

const TERMINAL_STATES: ReadonlySet<TaskState> = new Set([
  'MERGED',
  'DLQ',
  'ROLLED_BACK',
])

const REVOKING_EVENTS: ReadonlySet<TaskEvent> = new Set([
  'WATCHDOG_EXPIRE',
  'FAIL_QUALITY',
  'REJECT',
  'HALT',
  'EXHAUST_RETRIES',
])

const PROMOTING_EVENTS: ReadonlySet<TaskEvent> = new Set([
  'SUBMIT_VERIFICATION',
  'PASS_SCOPE',
  'PASS_QUALITY',
  'APPROVE',
  'CONFIRM_MERGE',
])

export function isTerminalState(state: TaskState): boolean {
  return TERMINAL_STATES.has(state)
}

export function isRevokingEvent(event: TaskEvent): boolean {
  return REVOKING_EVENTS.has(event)
}

export function isPromotingEvent(event: TaskEvent): boolean {
  return PROMOTING_EVENTS.has(event)
}

/**
 * Pure state machine transition evaluator.
 */
export function evaluateFsmTransition(
  currentState: TaskState,
  event: TaskEvent,
  context: TransitionContext,
): TransitionResult {
  // 1. Terminal states treat late events as safe no-ops
  if (TERMINAL_STATES.has(currentState)) {
    return {
      isValid: true,
      nextState: currentState,
      isTerminalNoOp: true,
    }
  }

  // 2. Universal non-destructive HALT from any non-terminal state
  if (event === 'HALT') {
    return {
      isValid: true,
      nextState: 'HALTED',
      isTerminalNoOp: false,
    }
  }

  // 3. Resume from HALTED back to PENDING
  if (currentState === 'HALTED' && event === 'RESUME') {
    return {
      isValid: true,
      nextState: 'PENDING',
      isTerminalNoOp: false,
    }
  }

  switch (currentState) {
    case 'PENDING':
      if (event === 'CLAIM_LEASE') {
        return { isValid: true, nextState: 'CLAIMED', isTerminalNoOp: false }
      }
      break

    case 'CLAIMED':
      if (event === 'ACK_RUNNING') {
        return { isValid: true, nextState: 'RUNNING', isTerminalNoOp: false }
      }
      if (event === 'WATCHDOG_EXPIRE') {
        const nextState =
          context.attemptCount + 1 >= context.maxAttempts ? 'DLQ' : 'RETRYING'
        return { isValid: true, nextState, isTerminalNoOp: false }
      }
      break

    case 'RUNNING':
      if (event === 'SUBMIT_VERIFICATION') {
        return { isValid: true, nextState: 'VERIFYING', isTerminalNoOp: false }
      }
      if (event === 'WATCHDOG_EXPIRE') {
        const nextState =
          context.attemptCount + 1 >= context.maxAttempts ? 'DLQ' : 'RETRYING'
        return { isValid: true, nextState, isTerminalNoOp: false }
      }
      break

    case 'VERIFYING':
      if (event === 'PASS_SCOPE') {
        return {
          isValid: true,
          nextState: 'SCOPE_PASSED',
          isTerminalNoOp: false,
        }
      }
      if (event === 'FAIL_QUALITY') {
        const nextState =
          context.attemptCount + 1 >= context.maxAttempts
            ? 'ROLLING_BACK'
            : 'RETRYING'
        return { isValid: true, nextState, isTerminalNoOp: false }
      }
      break

    case 'SCOPE_PASSED':
      if (event === 'PASS_QUALITY') {
        const nextState = context.isHighRisk ? 'AWAITING_APPROVAL' : 'MERGING'
        return { isValid: true, nextState, isTerminalNoOp: false }
      }
      if (event === 'FAIL_QUALITY') {
        const nextState =
          context.attemptCount + 1 >= context.maxAttempts
            ? 'ROLLING_BACK'
            : 'RETRYING'
        return { isValid: true, nextState, isTerminalNoOp: false }
      }
      break

    case 'AWAITING_APPROVAL':
      if (event === 'APPROVE') {
        return { isValid: true, nextState: 'MERGING', isTerminalNoOp: false }
      }
      if (event === 'REJECT') {
        return {
          isValid: true,
          nextState: 'ROLLING_BACK',
          isTerminalNoOp: false,
        }
      }
      break

    case 'MERGING':
      if (event === 'CONFIRM_MERGE') {
        return { isValid: true, nextState: 'MERGED', isTerminalNoOp: false }
      }
      break

    case 'RETRYING':
      if (event === 'RETRY') {
        return { isValid: true, nextState: 'PENDING', isTerminalNoOp: false }
      }
      if (event === 'EXHAUST_RETRIES') {
        return { isValid: true, nextState: 'DLQ', isTerminalNoOp: false }
      }
      break

    case 'ROLLING_BACK':
      if (event === 'ROLLBACK_COMPLETE') {
        return {
          isValid: true,
          nextState: 'ROLLED_BACK',
          isTerminalNoOp: false,
        }
      }
      break

    default:
      break
  }

  return {
    isValid: false,
    nextState: currentState,
    isTerminalNoOp: false,
    error: `ILLEGAL_STATE_TRANSITION: Event '${event}' is invalid from state '${currentState}'.`,
  }
}
```

```typescript
import {
  evaluateFsmTransition,
  isRevokingEvent,
  isTerminalState,
  type TaskState,
  type TaskEvent,
  type TransitionContext,
} from '../fsm/transitions.js'

export interface TaskRecord {
  taskId: string
  fsmState: TaskState
  currentEpoch: number
  leaseExpiresAt: number
  attemptCount: number
  maxAttempts: number
  activeWorkerId: string | null
  isHighRisk: boolean
  updatedAt: number
}

export interface ClaimLeaseResponse {
  ok: boolean
  taskId: string
  epoch: number
  leaseExpiresAt: number
  fsmState: TaskState
}

export interface HeartbeatResponse {
  ok: boolean
  epoch: number
  leaseExpiresAt: number
}

export interface CompletionResponse {
  ok: boolean
  fsmState: TaskState
  epoch: number
}

export class ShotCoordinatorDO {
  private taskId = ''
  private fsmState: TaskState = 'PENDING'
  private currentEpoch = 0
  private leaseExpiresAt = 0
  private attemptCount = 0
  private maxAttempts = 3
  private activeWorkerId: string | null = null
  private isHighRisk = false
  private updatedAt = Date.now()

  constructor(
    private ctx: any,
    private env: any,
  ) {
    // Rehydration Boot Barrier: block concurrency while loading from NVMe storage
    this.ctx.blockConcurrencyWhile?.(async () => {
      const record = await this.ctx.storage.get('task_record')
      if (record && typeof record === 'object') {
        this.taskId = record.taskId || ''
        this.fsmState = record.fsmState || 'PENDING'
        this.currentEpoch = Number(record.currentEpoch || 0)
        this.leaseExpiresAt = Number(record.leaseExpiresAt || 0)
        this.attemptCount = Number(record.attemptCount || 0)
        this.maxAttempts = Number(record.maxAttempts || 3)
        this.activeWorkerId = record.activeWorkerId || null
        this.isHighRisk = Boolean(record.isHighRisk)
        this.updatedAt = Number(record.updatedAt || Date.now())
        console.log(
          `>> [DO:REHYDRATE] Task '${this.taskId}' loaded in state '${this.fsmState}', Epoch: ${this.currentEpoch} [OK]`,
        )
      }
    })
  }

  /**
   * Unified State Choke Point: all state mutations must execute through this atomic method.
   */
  async applyTransition(
    event: TaskEvent,
    actor: { type: string; id: string; epoch?: number },
    payload?: any,
  ): Promise<TaskRecord> {
    const context: TransitionContext = {
      attemptCount: this.attemptCount,
      maxAttempts: this.maxAttempts,
      isHighRisk: this.isHighRisk,
    }

    const result = evaluateFsmTransition(this.fsmState, event, context)
    if (!result.isValid) {
      console.error(`>> [FSM:REJECT] ${result.error} [FAIL]`)
      throw new Error(result.error)
    }

    // Terminal states treat incoming events as safe no-ops
    if (result.isTerminalNoOp) {
      console.log(
        `>> [FSM:TERMINAL_NOOP] Ignored event '${event}' on terminal state '${this.fsmState}' [OK]`,
      )
      return this.getSnapshot()
    }

    const previousState = this.fsmState
    const nextState = result.nextState

    // Self-transition guard
    if (previousState === nextState) {
      return this.getSnapshot()
    }

    // Monotonic Epoch Fencing: increment counter on claim, revoking events, or retry
    if (
      event === 'CLAIM_LEASE' ||
      isRevokingEvent(event) ||
      event === 'RETRY'
    ) {
      this.currentEpoch += 1
      console.log(
        `>> [EPOCH:BUMP] Advanced epoch to ${this.currentEpoch} on event '${event}' [OK]`,
      )
    }

    // Update state and attempts
    this.fsmState = nextState
    this.updatedAt = Date.now()

    if (event === 'CLAIM_LEASE') {
      this.attemptCount += 1
      this.activeWorkerId = actor.id || null
      this.leaseExpiresAt = Date.now() + 30_000
    }

    // Hardware Watchdog Alarm Reconciliation
    if (nextState === 'RUNNING') {
      await this.ctx.storage.setAlarm(Date.now() + 30_000)
      console.log(
        `>> [WATCHDOG:ARM] Armed 30s alarm for task '${this.taskId}' (Epoch: ${this.currentEpoch}) [OK]`,
      )
    } else if (previousState === 'RUNNING' && nextState !== 'RUNNING') {
      await this.ctx.storage.deleteAlarm()
      console.log(
        `>> [WATCHDOG:DISARM] Deleted alarm on exit from RUNNING to '${nextState}' [OK]`,
      )
    }

    if (isTerminalState(nextState)) {
      await this.ctx.storage.deleteAlarm()
      this.activeWorkerId = null
      this.leaseExpiresAt = 0
    }

    // Commit state snapshot atomically
    const snapshot = this.getSnapshot()
    await this.ctx.storage.put('task_record', snapshot)

    console.log(
      `>> [FSM:TRANSITION] '${previousState}' -> '${nextState}' via '${event}' (Epoch: ${this.currentEpoch}) [OK]`,
    )
    return snapshot
  }

  /**
   * Proactive Hardware Watchdog Alarm Hook.
   * Fires when 30 seconds elapse without a valid worker heartbeat.
   */
  async alarm(): Promise<void> {
    console.warn(
      `>> [WATCHDOG:EXPIRE] Watchdog fired for task '${this.taskId}' in state '${this.fsmState}' [ALERT]`,
    )

    if (this.fsmState === 'RUNNING' || this.fsmState === 'CLAIMED') {
      // Worker timed out. Bump epoch and advance to RETRYING or DLQ
      await this.applyTransition('WATCHDOG_EXPIRE', {
        type: 'SYSTEM',
        id: 'WATCHDOG_ALARM',
      })
    }
  }

  /**
   * HTTP / RPC Router for DO requests.
   */
  async fetch(request: Request): Promise<Response> {
    const url = new URL(request.url)

    try {
      if (request.method === 'POST' && url.pathname.endsWith('/leases/claim')) {
        const body = await request.json().catch(() => ({}))
        const workerId = (body as any).workerId || 'UNKNOWN_WORKER'

        if (this.fsmState !== 'PENDING') {
          return new Response(
            JSON.stringify({
              error: `TASK_UNAVAILABLE: Current state is '${this.fsmState}'`,
            }),
            { status: 409, headers: { 'Content-Type': 'application/json' } },
          )
        }

        if (!this.taskId) {
          this.taskId = (body as any).taskId || 'task-default'
          this.isHighRisk = Boolean((body as any).isHighRisk)
        }

        const record = await this.applyTransition('CLAIM_LEASE', {
          type: 'WORKER',
          id: workerId,
        })

        const res: ClaimLeaseResponse = {
          ok: true,
          taskId: record.taskId,
          epoch: record.currentEpoch,
          leaseExpiresAt: record.leaseExpiresAt,
          fsmState: record.fsmState,
        }

        return new Response(JSON.stringify(res), {
          status: 200,
          headers: { 'Content-Type': 'application/json' },
        })
      }

      if (
        request.method === 'POST' &&
        url.pathname.endsWith('/leases/acknowledge')
      ) {
        const body = (await request.json().catch(() => ({}))) as any
        const { workerId, epoch } = body

        if (epoch !== this.currentEpoch) {
          return new Response(
            JSON.stringify({
              error: `STALE_EPOCH: Presented ${epoch}, Active ${this.currentEpoch}`,
            }),
            { status: 409, headers: { 'Content-Type': 'application/json' } },
          )
        }

        const record = await this.applyTransition('ACK_RUNNING', {
          type: 'WORKER',
          id: workerId,
        })

        return new Response(
          JSON.stringify({
            ok: true,
            fsmState: record.fsmState,
            epoch: record.currentEpoch,
          }),
          {
            status: 200,
            headers: { 'Content-Type': 'application/json' },
          },
        )
      }

      if (
        request.method === 'POST' &&
        url.pathname.endsWith('/leases/heartbeat')
      ) {
        const body = (await request.json().catch(() => ({}))) as any
        const { workerId, epoch } = body

        // Fencing Token Verification
        if (epoch !== this.currentEpoch) {
          console.warn(
            `>> [LEASE:CONFLICT] Heartbeat rejected: Presented Epoch ${epoch} < Active Epoch ${this.currentEpoch} [FAIL]`,
          )
          return new Response(
            JSON.stringify({
              error: `HTTP 409 Conflict: Stale Epoch ${epoch}. Active is ${this.currentEpoch}`,
            }),
            { status: 409, headers: { 'Content-Type': 'application/json' } },
          )
        }

        if (this.fsmState !== 'RUNNING') {
          return new Response(
            JSON.stringify({
              error: `INVALID_STATE: Task is in state '${this.fsmState}', not RUNNING`,
            }),
            { status: 409, headers: { 'Content-Type': 'application/json' } },
          )
        }

        // Extend lease window and reschedule hardware watchdog alarm
        const newExpiry = Date.now() + 30_000
        this.leaseExpiresAt = newExpiry
        this.updatedAt = Date.now()

        await this.ctx.storage.setAlarm(newExpiry)
        await this.ctx.storage.put('task_record', this.getSnapshot())

        const res: HeartbeatResponse = {
          ok: true,
          epoch: this.currentEpoch,
          leaseExpiresAt: this.leaseExpiresAt,
        }

        return new Response(JSON.stringify(res), {
          status: 200,
          headers: { 'Content-Type': 'application/json' },
        })
      }

      if (
        request.method === 'POST' &&
        url.pathname.endsWith('/tasks/complete')
      ) {
        const body = (await request.json().catch(() => ({}))) as any
        const { workerId, epoch, payload } = body

        // Monotonic Fencing Token Check (Zombie Runner Defense)
        if (epoch !== this.currentEpoch) {
          console.warn(
            `>> [ZOMBIE:REJECT] Promotion rejected: Stale Epoch ${epoch} != Active Epoch ${this.currentEpoch} [FAIL]`,
          )
          return new Response(
            JSON.stringify({
              error: `HTTP 409 Conflict: Stale Epoch ${epoch}. Active Epoch is ${this.currentEpoch}`,
            }),
            { status: 409, headers: { 'Content-Type': 'application/json' } },
          )
        }

        const record = await this.applyTransition(
          'SUBMIT_VERIFICATION',
          { type: 'WORKER', id: workerId },
          payload,
        )

        const res: CompletionResponse = {
          ok: true,
          fsmState: record.fsmState,
          epoch: record.currentEpoch,
        }

        return new Response(JSON.stringify(res), {
          status: 200,
          headers: { 'Content-Type': 'application/json' },
        })
      }

      if (request.method === 'GET' && url.pathname.endsWith('/state')) {
        return new Response(JSON.stringify(this.getSnapshot()), {
          status: 200,
          headers: { 'Content-Type': 'application/json' },
        })
      }

      return new Response('NOT_FOUND', { status: 404 })
    } catch (err: any) {
      console.error(`>> [DO:ERROR] ${err.message || String(err)}`)
      return new Response(
        JSON.stringify({ error: err.message || 'INTERNAL_ERROR' }),
        {
          status: 500,
          headers: { 'Content-Type': 'application/json' },
        },
      )
    }
  }

  private getSnapshot(): TaskRecord {
    return {
      taskId: this.taskId,
      fsmState: this.fsmState,
      currentEpoch: this.currentEpoch,
      leaseExpiresAt: this.leaseExpiresAt,
      attemptCount: this.attemptCount,
      maxAttempts: this.maxAttempts,
      activeWorkerId: this.activeWorkerId,
      isHighRisk: this.isHighRisk,
      updatedAt: this.updatedAt,
    }
  }
}
```
