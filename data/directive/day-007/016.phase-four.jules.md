1. **IMMUTABLE RUNNER BOUNDARY:** You are strictly forbidden from creating,
   altering, touching, or deleting any file inside `apps/995.library/`.

2. **WORKSPACE QUARANTINE:** All modifications and file creations are
   quarantined strictly to `apps/worker`. Do not touch sibling packages in
   `packages/*`.

3. **DEPENDENCY PURITY:** Zero third-party socket, HTTP, or streaming libraries
   (no `ws`, `socket.io`, `socket.io-client`, `axios`, `@octokit/*`,
   `@slack/*`). Rely exclusively on Cloudflare Workers native runtime APIs
   (`WebSocketPair`, `DurableObject`, `DurableObjectState`), native Web
   Standards (`Request`, `Response`, `fetch`), and standard Node.js built-ins.

4. **PURE 7-BIT ASCII TELEMETRY:** Zero multi-byte UTF-8 emojis across all
   source code, comments, log strings, and test descriptions. Enforce pure 7-bit
   ASCII tokens (`>>`, `[OK]`, `[FAIL]`, `::`, `[WS]`, `[HIBERNATE]`, `[RELAY]`,
   `[BROADCAST]`, `[REPLAY]`).

5. **ZERO-COST HIBERNATION INVARIANT:** Every client socket must be accepted
   using Cloudflare's WebSocket Hibernation API
   (`this.ctx.acceptWebSocket(server, [role])`). The Durable Object must never
   maintain active `setInterval` ping loops or prevent isolate eviction while
   waiting on 60–120 second GPU rendering passes, ensuring idle compute cost
   remains $0.00.

6. **ROLE ISOLATION & PARTITIONING:** Inbound telemetry frames from physical
   hardware spokes (`role=broker`) must never be broadcast to other hardware
   spokes; they must multiplex strictly to client viewports (`role=artist` or
   `role=operator`). Binary preview suppression must be enforced at the gateway.

7. **MONOTONIC SEQUENCE STAMPING:** Every telemetry frame broadcast from the
   edge must be stamped with a strictly increasing integer sequence counter
   (`seq: N + 1`). Reconnecting clients must receive historical replay buffers
   before live streams to guarantee zero-gap telemetry continuity.

### II. ARCHITECTURAL REQUIREMENTS

#### 1. Wire Protocol & Sensory Relay Definitions (`apps/worker/src/telemetry/sensoryRelay.ts`)

- **Role Taxonomy:**
- `'operator'`: Blessed Curses TUI terminal cockpit (`cns00`).

- `'artist'`: Web-based Astro / React showrunner cockpit.

- `'broker'`: Headless GPU rendering daemon on Rig 2 (`media-broker`).

- **Envelope Schemas:**
- `SensoryPacket`:
  `{ type: string; source: string; timestampMs: number; payload: any; ascii?: string }`.

- `TelemetryEnvelope`: `SensoryPacket & { seq: number }`.

- `HistoricalReplayEnvelope`:
  `{ type: 'TELEMETRY_HISTORY'; seq: number; payload: { items: TelemetryEnvelope[] } }`.

- **Constants:**
- `MAX_RING_BUFFER_SIZE = 50` (Maximum historical telemetry envelopes retained
  in NVMe/memory).

#### 2. Durable Object Hibernation Multiplexer (`apps/worker/src/objects/ShotCoordinatorDO.ts`)

- **Ingress Handshake (`fetch(request)`):**
- Validates `request.headers.get("Upgrade") === "websocket"`; returns
  `HTTP 426 Upgrade Required` otherwise.

- Extracts `role` query parameter (defaulting to `'operator'`).

- Instantiates `new WebSocketPair()`, accepts the server socket via
  `this.ctx.acceptWebSocket(server, [role])`, and immediately transmits the
  `TELEMETRY_HISTORY` replay packet to the newly connected client.

- Returns `new Response(null, { status: 101, webSocket: client })`.

- **Hibernation Callbacks:**
- `webSocketMessage(ws, message)`: Deserializes JSON payloads. If the sender is
  tagged `'broker'`, intercepts `BROKER_PROGRESS`, stamps it with
  `seq: ++this.currentSeq`, updates the ring buffer, and relays it strictly to
  `this.ctx.getWebSockets("artist")` and `this.ctx.getWebSockets("operator")`.

- `webSocketClose(ws, code, reason, wasClean)`: Cleans up disconnected state
  without throwing.

- `webSocketError(ws, error)`: Traps socket exceptions with standardized ASCII
  logging.

- **Direct RPC Broadcaster (`broadcastTelemetry(packet)`):**
- Allows external worker routes and daemons (e.g., `jules.ts`, `pinVerifier.ts`)
  to invoke telemetry relays programmatically via DO stub.

- Assigns the next monotonic sequence number, records to the ring buffer, and
  multiplexes to all active client sockets (`operator` and `artist`).

#### 3. Root Edge Gateway Route (`apps/worker/src/index.ts`)

- Mount `GET /ws/telemetry` on the main Hono router.

- Assert `header('Upgrade') === 'websocket'`; reject invalid HTTP calls with
  `HTTP 426`.

- Forward the raw request directly to
  `env.REPO_BOT_DO.idFromName('global').fetch(c.req.raw)` to initiate the 101
  Switching Protocols upgrade.

#### 4. Automated Vitest Verification Battery (`apps/worker/test/unit/websocketMultiplexer.test.ts`)

- Verify that missing `Upgrade` header returns `HTTP 426 Upgrade Required`.

- Verify successful WebSocket upgrade returns `HTTP 101` and invokes
  `ctx.acceptWebSocket` with the provided role tag.

- Verify immediate transmission of `TELEMETRY_HISTORY` upon client connection.

- Verify monotonic sequence stamping (`seq: 1, 2, 3...`) across successive
  broadcasts.

- Verify role isolation: broker progress packets route to `artist` and
  `operator` sockets, never back to `broker` sockets.

- Verify ring buffer maintains bounded size ($M \le 50$) under high-frequency
  event bursts.

```typescript
export type TelemetryRole = 'operator' | 'artist' | 'broker'

export interface SensoryPacket {
  type: string
  source: string
  timestampMs?: number
  payload: Record<string, any>
  ascii?: string
}

export interface TelemetryEnvelope extends SensoryPacket {
  seq: number
  timestampMs: number
}

export interface HistoricalReplayEnvelope {
  type: 'TELEMETRY_HISTORY'
  seq: number
  payload: {
    items: TelemetryEnvelope[]
  }
}

export const MAX_RING_BUFFER_SIZE = 50

/**
 * Validates and sanitizes the requested WebSocket role tag.
 */
export function sanitizeRoleTag(roleParam: string | null): TelemetryRole {
  if (roleParam === 'artist') return 'artist'
  if (roleParam === 'broker') return 'broker'
  return 'operator'
}
```

#### 2. Create `apps/worker/src/objects/ShotCoordinatorDO.ts`

```typescript
import {
  sanitizeRoleTag,
  type TelemetryRole,
  type SensoryPacket,
  type TelemetryEnvelope,
  type HistoricalReplayEnvelope,
  MAX_RING_BUFFER_SIZE,
} from '../telemetry/sensoryRelay.js'

export class ShotCoordinatorDO {
  private currentSeq = 0
  private ringBuffer: TelemetryEnvelope[] = []

  constructor(
    private ctx: any,
    private env: any,
  ) {
    // Hydrate sequence state and ring buffer from NVMe storage if available
    this.ctx.blockConcurrencyWhile?.(async () => {
      const storedSeq = await this.ctx.storage.get('currentSeq')
      if (typeof storedSeq === 'number') {
        this.currentSeq = storedSeq
      }
      const storedBuffer = await this.ctx.storage.get('ringBuffer')
      if (Array.isArray(storedBuffer)) {
        this.ringBuffer = storedBuffer
      }
    })
  }

  /**
   * Ingress gateway handling WebSocket upgrade requests.
   */
  async fetch(request: Request): Promise<Response> {
    const url = new URL(request.url)

    // RPC Telemetry Broadcast Route (HTTP POST from Edge Worker Isolates)
    if (request.method === 'POST' && url.pathname.endsWith('/broadcast')) {
      const packet: SensoryPacket = await request.json()
      const envelope = await this.recordAndBroadcast(packet)
      return new Response(JSON.stringify({ ok: true, seq: envelope.seq }), {
        status: 200,
        headers: { 'Content-Type': 'application/json' },
      })
    }

    // WebSocket Telemetry Ingress Route
    if (request.headers.get('Upgrade') !== 'websocket') {
      return new Response('Expected Upgrade: websocket', {
        status: 426,
        headers: { Upgrade: 'websocket' },
      })
    }

    const role = sanitizeRoleTag(url.searchParams.get('role'))
    const pair = new WebSocketPair()
    const client = pair[0]
    const server = pair[1]

    // Register socket under WebSocket Hibernation API with role tag
    this.ctx.acceptWebSocket(server, [role])

    // Transmit historical replay buffer immediately upon connection to client viewports
    if (role === 'operator' || role === 'artist') {
      const replay: HistoricalReplayEnvelope = {
        type: 'TELEMETRY_HISTORY',
        seq: this.currentSeq,
        payload: {
          items: [...this.ringBuffer],
        },
      }
      server.send(JSON.stringify(replay))
    }

    console.log(
      `>> [WS:CONNECT] Accepted ${role} WebSocket connection (Seq: ${this.currentSeq}) [OK]`,
    )

    return new Response(null, {
      status: 101,
      webSocket: client,
    })
  }

  /**
   * WebSocket Hibernation Callback: Invoked when a connected socket transmits a message.
   */
  async webSocketMessage(
    ws: WebSocket,
    message: string | ArrayBuffer,
  ): Promise<void> {
    if (typeof message !== 'string') {
      return // Suppress binary visual previews to preserve edge bandwidth
    }

    try {
      const data = JSON.parse(message)
      const tags: string[] = this.ctx.getTags ? this.ctx.getTags(ws) : []
      const isBroker = tags.includes('broker')

      // Handle incoming telemetry progress from GPU foundry media-broker
      if (
        isBroker &&
        (data.type === 'BROKER_PROGRESS' || data.type === 'BROKER_HEARTBEAT')
      ) {
        await this.recordAndBroadcast({
          type: data.type,
          source: 'rig2_media_broker',
          payload: data.payload || data,
          ascii:
            data.ascii ||
            `>> [GPU PROGRESS] Task ${data.taskId || 'active'}: ${data.progress || 0}%`,
        })
      }
    } catch (err: any) {
      console.error(
        `>> [WS:PARSE_ERR] Malformed frame received: ${err.message}`,
      )
    }
  }

  /**
   * WebSocket Hibernation Callback: Clean closure lifecycle hook.
   */
  async webSocketClose(
    ws: WebSocket,
    code: number,
    reason: string,
    wasClean: boolean,
  ): Promise<void> {
    console.log(
      `>> [WS:CLOSE] Socket disconnected (Code: ${code}, Reason: ${reason || 'NONE'})`,
    )
  }

  /**
   * WebSocket Hibernation Callback: Socket transport exception hook.
   */
  async webSocketError(ws: WebSocket, error: unknown): Promise<void> {
    console.error(`>> [WS:FAIL] Socket exception encountered: ${error}`)
  }

  /**
   * Stamped broadcast helper: increments seq, appends to ring buffer, and relays across roles.
   */
  private async recordAndBroadcast(
    packet: SensoryPacket,
  ): Promise<TelemetryEnvelope> {
    this.currentSeq += 1
    const envelope: TelemetryEnvelope = {
      ...packet,
      seq: this.currentSeq,
      timestampMs: packet.timestampMs || Date.now(),
    }

    // Maintain bounded ring buffer
    this.ringBuffer.push(envelope)
    if (this.ringBuffer.length > MAX_RING_BUFFER_SIZE) {
      this.ringBuffer.shift()
    }

    // Persist to storage without blocking live fan-out
    this.ctx.storage?.put?.('currentSeq', this.currentSeq).catch?.(() => {})
    this.ctx.storage?.put?.('ringBuffer', this.ringBuffer).catch?.(() => {})

    const serialized = JSON.stringify(envelope)

    // Multiplex strictly to client viewports (operator and artist)
    const recipientSockets: WebSocket[] = [
      ...(this.ctx.getWebSockets?.('operator') || []),
      ...(this.ctx.getWebSockets?.('artist') || []),
    ]

    for (const socket of recipientSockets) {
      try {
        socket.send(serialized)
      } catch {
        // Sockets closing asynchronously will be reaped cleanly by the runtime
      }
    }

    return envelope
  }
}
```

#### 4. Create `apps/worker/test/unit/websocketMultiplexer.test.ts`

```typescript
import { describe, it, expect, vi, beforeEach } from 'vitest'
import { ShotCoordinatorDO } from '../../src/objects/ShotCoordinatorDO.js'
import type { SensoryPacket } from '../../src/telemetry/sensoryRelay.js'

class MockWebSocket {
  public sentMessages: string[] = []
  public closed = false

  send(msg: string) {
    this.sentMessages.push(msg)
  }

  close() {
    this.closed = true
  }
}

class MockDurableObjectState {
  public storageData = new Map<string, any>()
  public acceptedSockets: Array<{ ws: MockWebSocket; tags: string[] }> = []

  public storage = {
    get: async (key: string) => this.storageData.get(key),
    put: async (key: string, val: any) => {
      this.storageData.set(key, val)
    },
  }

  acceptWebSocket(ws: any, tags: string[] = []) {
    this.acceptedSockets.push({ ws, tags })
  }

  getWebSockets(tag?: string) {
    if (!tag) return this.acceptedSockets.map((s) => s.ws)
    return this.acceptedSockets
      .filter((s) => s.tags.includes(tag))
      .map((s) => s.ws)
  }

  getTags(ws: any) {
    const found = this.acceptedSockets.find((s) => s.ws === ws)
    return found ? found.tags : []
  }

  blockConcurrencyWhile(fn: () => Promise<any>) {
    return fn()
  }
}

describe('WebSocket Multiplexing & Sensory Relay Battery (Phase 4)', () => {
  let mockCtx: MockDurableObjectState
  let coordinator: ShotCoordinatorDO

  beforeEach(() => {
    mockCtx = new MockDurableObjectState()
    coordinator = new ShotCoordinatorDO(mockCtx as any, {})
  })

  it('TASK-4.1: rejects non-WebSocket requests with HTTP 426 Upgrade Required', async () => {
    const req = new Request('https://edge.repo-bot/ws/telemetry', {
      method: 'GET',
      headers: { Accept: 'application/json' },
    })

    const res = await coordinator.fetch(req)
    expect(res.status).toBe(426)
    expect(res.headers.get('Upgrade')).toBe('websocket')
  })

  it('TASK-4.1 & 4.2: accepts client socket with role tag and sends TELEMETRY_HISTORY replay', async () => {
    const req = new Request(
      'https://edge.repo-bot/ws/telemetry?role=operator',
      {
        method: 'GET',
        headers: { Upgrade: 'websocket' },
      },
    )

    const res = await coordinator.fetch(req)
    expect(res.status).toBe(101)
    expect(mockCtx.acceptedSockets).toHaveLength(1)
    expect(mockCtx.acceptedSockets[0].tags).toEqual(['operator'])

    // Verify history replay packet sent to client
    const serverSocket = mockCtx.acceptedSockets[0].ws
    expect(serverSocket.sentMessages).toHaveLength(1)
    const replay = JSON.parse(serverSocket.sentMessages[0])
    expect(replay.type).toBe('TELEMETRY_HISTORY')
    expect(Array.isArray(replay.payload.items)).toBe(true)
  })

  it('TASK-4.2 & 4.3: broadcasts stamped telemetry sequentially with monotonic seq numbering', async () => {
    // Connect an operator socket and an artist socket
    const opReq = new Request(
      'https://edge.repo-bot/ws/telemetry?role=operator',
      {
        headers: { Upgrade: 'websocket' },
      },
    )
    const artReq = new Request(
      'https://edge.repo-bot/ws/telemetry?role=artist',
      {
        headers: { Upgrade: 'websocket' },
      },
    )

    await coordinator.fetch(opReq)
    await coordinator.fetch(artReq)

    const opSocket = mockCtx.acceptedSockets[0].ws
    const artSocket = mockCtx.acceptedSockets[1].ws

    // Clear the initial TELEMETRY_HISTORY greeting packet
    opSocket.sentMessages.length = 0
    artSocket.sentMessages.length = 0

    // Broadcast external RPC packet
    const packet: SensoryPacket = {
      type: 'JULES_EVENT',
      source: 'julesDispatcher',
      payload: { taskId: 'TASK-01' },
      ascii: '>> [JULES] Dispatched',
    }

    const postReq = new Request('https://edge.repo-bot/broadcast', {
      method: 'POST',
      body: JSON.stringify(packet),
    })

    const rpcRes = await coordinator.fetch(postReq)
    const rpcJson = await rpcRes.json()
    expect(rpcJson.seq).toBe(1)

    // Assert both viewports received the stamped envelope
    expect(opSocket.sentMessages).toHaveLength(1)
    expect(artSocket.sentMessages).toHaveLength(1)

    const opMsg = JSON.parse(opSocket.sentMessages[0])
    expect(opMsg.seq).toBe(1)
    expect(opMsg.type).toBe('JULES_EVENT')
  })

  it('TASK-4.3: relays broker progress packets strictly to viewports without echoing to broker sockets', async () => {
    // Connect 1 broker and 1 operator
    const brokerReq = new Request(
      'https://edge.repo-bot/ws/telemetry?role=broker',
      {
        headers: { Upgrade: 'websocket' },
      },
    )
    const opReq = new Request(
      'https://edge.repo-bot/ws/telemetry?role=operator',
      {
        headers: { Upgrade: 'websocket' },
      },
    )

    await coordinator.fetch(brokerReq)
    await coordinator.fetch(opReq)

    const brokerSocket = mockCtx.acceptedSockets[0].ws
    const opSocket = mockCtx.acceptedSockets[1].ws
    opSocket.sentMessages.length = 0

    // Broker sends progress frame
    await coordinator.webSocketMessage(
      brokerSocket as any,
      JSON.stringify({
        type: 'BROKER_PROGRESS',
        taskId: 'SHOT-99',
        progress: 65,
      }),
    )

    // Operator must receive the relay; Broker must NOT receive its own message echoed
    expect(opSocket.sentMessages).toHaveLength(1)
    expect(brokerSocket.sentMessages).toHaveLength(0)

    const relayed = JSON.parse(opSocket.sentMessages[0])
    expect(relayed.type).toBe('BROKER_PROGRESS')
    expect(relayed.payload.progress).toBe(65)
  })

  it('TASK-4.2: caps ring buffer at MAX_RING_BUFFER_SIZE (50) under heavy load', async () => {
    for (let i = 1; i <= 60; i++) {
      await coordinator.fetch(
        new Request('https://edge.repo-bot/broadcast', {
          method: 'POST',
          body: JSON.stringify({
            type: 'TICK',
            source: 'test',
            payload: { count: i },
          }),
        }),
      )

    // Connect new operator to inspect replay length
    const req = new Request(
      'https://edge.repo-bot/ws/telemetry?role=operator',
      {
        headers: { Upgrade: 'websocket' },
      },
    )
    await coordinator.fetch(req)

    const newSocket =
      mockCtx.acceptedSockets[mockCtx.acceptedSockets.length - 1].ws
    const replay = JSON.parse(newSocket.sentMessages[0])
    expect(replay.payload.items).toHaveLength(50)
    expect(replay.payload.items[0].payload.count).toBe(11) // Oldest 10 evicted
    expect(replay.payload.items[49].payload.count).toBe(60)
  })
})
```
