### II. ARCHITECTURAL REQUIREMENTS

#### 1. Taxonomy-Grounded Prompt Synthesizer (`apps/worker/src/remediation/promptSynthesizer.ts`)

- **Closed-Taxonomy Remediation Strategies:**
- `HARMLESS_FLOAT_NOISE`: Preserves existing positive/negative prompts. Perturbs
  execution seed ($S \to S + 1013$) and applies micro-adjustment to denoise
  strength ($-0.02$).
- `LIGHTING_CURVE_SHIFT`: Injects photometric balancing tokens into positive
  prompt (`balanced key lighting, neutral color grade, studio illumination`) and
  appends lighting negative tokens
  (`blown out highlights, crushed shadows, harsh clipping, severe color tint`).
- `ANATOMICAL_COLLAPSE`: Injects anatomical stabilization anchors
  (`anatomically correct proportions, symmetric facial structure, intact hands and fingers`)
  and amplifies high-weight negative constraints
  (`bad anatomy, deformed limbs, extra fingers, fused digits, missing fingers, warped eyes, facial collapse`).
- `CANON_INVARIANT_BREACH`: Injects canon invariant markers from character lore
  and converts detected anachronisms directly into explicit negative exclusions
  (e.g., if `anachronismsDetected = ['zipper', 'modern_fabric']`, synthesizes
  negative prompt tokens
  `zipper, modern zipper, modern synthetic fabric, plastic seams`).

- **Constraint Deduplication & Budget Guard:**
- `deduplicateTokens(commaSeparated: string): string`: Splits by comma, trims,
  lowercases for collision checking, filters empty/whitespace items, and
  reconstructs comma-separated output.
- `enforceTokenCeiling(prompt: string, maxCharacters = 1500): string`: Truncates
  at the nearest comma boundary below ceiling to prevent ComfyUI CLIP buffer
  overflows.

#### 2. Autonomous Remediation Cycle Engine (`apps/worker/src/remediation/remediationEngine.ts`)

- **Remediation Evaluation Flow (`RemediationEngine.evaluateAndRemediate`):**

1. Ingests `CandidatePlate`, `GauntletResult`, and active `ExecutionJob`.
2. If candidate passed all gauntlet tiers, returns
   `{ status: 'APPROVED', promoted: true }`.
3. If candidate failed at Tier 1 (format/dimension violation), aborts
   remediation immediately with `{ status: 'FATAL_FORMAT_ERROR' }` (cannot be
   fixed via prompt synthesis).
4. Extracts `VlmAuditReport` and checks circuit breaker evaluation:

- If circuit breaker status is `DIVERGENT_STRUCTURAL_CONFLICT` or
  `CIRCUIT_BREAKER_TRIPPED`: halts execution, marks job as quarantined, logs
  escalation dossier, and returns `{ status: 'HALTED_BLOCKED', dossier }`.
- If status is `ALLOW_CYCLE_RETRY`: executes `synthesizeRemediatedPrompt`,
  increments `job.attemptCount`, advances seed, updates `job.prompts`, and
  generates an updated `ExecutionJob`.

- **Diagnostic Telemetry:**
- Logs ASCII event:
  `>> [REMEDIATE:CYCLE] Task '${taskId}' remediated (Attempt ${nextAttempt}/${maxAttempts}) under strategy '${classification}' [OK]`.

#### 3. DO Queue Re-enqueue Integration (`apps/worker/src/objects/ShotCoordinatorDO.ts`)

- **Remediation Re-enqueue Hook:**
- Exposes `POST /tasks/remediate` or handles internal re-enqueueing upon audit
  failure.
- When gauntlet evaluation allows retry, increments monotonic epoch
  ($N \to N+1$), replaces `activeJob` prompts with remediated prompts, and
  re-queues the task via `this.fairQueue.requeue(remediatedJob)`.
- Records an immutable block into `ledgerChain`:
  `appendLedgerEntry(this.ledgerChain, 'AUTONOMOUS_REMEDIATION_REQUEUE', { attemptCount, classification, promptDiff })`.
- Arms hardware watchdog alarm and commits updated snapshot to `ctx.storage`.

#### 4. Automated Vitest Verification Battery (`apps/worker/test/unit/autonomousRemediation.test.ts`)

- Verify prompt patching for all 4 taxonomy categories (`HARMLESS_FLOAT_NOISE`,
  `LIGHTING_CURVE_SHIFT`, `ANATOMICAL_COLLAPSE`, `CANON_INVARIANT_BREACH`).
- Verify conversion of detected anachronisms into explicit negative prompt

- Verify negative prompt deduplication preserves unique tokens without infinite

import type {
  DriftClassification,
  VlmAuditReport,
} from '../triage/visualScanTrace.js'

export interface PromptPayload {
  positivePrompt: string
  negativePrompt: string
  denoiseStrength?: number
  seed?: number
  extraParameters?: Record<string, any>
}

export interface PromptPatchResult {
  patchedPrompts: PromptPayload
  strategyApplied: DriftClassification
  diffSummary: string
  tokensAdded: string[]
}

export const MAX_PROMPT_CHARACTERS = 1500

/**
 * Deduplicates comma-separated prompt tokens while preserving original casing and order.
 */
export function deduplicateTokens(commaSeparated: string): string {
  const tokens = commaSeparated
    .split(',')
    .map((t) => t.trim())
    .filter((t) => t.length > 0)
  const seen = new Set<string>()
  const deduplicated: string[] = []

  for (const token of tokens) {
    const normalized = token.toLowerCase()
    if (!seen.has(normalized)) {
      seen.add(normalized)
      deduplicated.push(token)
    }
  }

  return deduplicated.join(', ')
}

/**
 * Enforces maximum prompt character ceiling to prevent CLIP buffer overflow.
 */
export function enforceTokenCeiling(
  prompt: string,
  maxCharacters = MAX_PROMPT_CHARACTERS,
): string {
  if (prompt.length <= maxCharacters) {
    return prompt
  }

  const truncated = prompt.substring(0, maxCharacters)
  const lastComma = truncated.lastIndexOf(',')
  if (lastComma > 0) {
    return truncated.substring(0, lastComma).trim()
  }
  return truncated.trim()
}

/**
 * Synthesizes taxonomy-grounded prompt adjustments and negative constraint amplifications.
 */
export function synthesizeRemediatedPrompt(
  currentPrompts: PromptPayload,
  auditReport: VlmAuditReport,
  currentAttempt: number,
): PromptPatchResult {
  const classification = auditReport.classification
  let positive = currentPrompts.positivePrompt
  let negative = currentPrompts.negativePrompt
  let seed = currentPrompts.seed ?? 42
  let denoise = currentPrompts.denoiseStrength ?? 1.0
  const tokensAdded: string[] = []

  switch (classification) {
    case 'HARMLESS_FLOAT_NOISE': {
      // Seed perturbation and minor denoise clamp
      seed = seed + 1013 * currentAttempt
      denoise = Math.max(0.2, denoise - 0.02)
      break
    }

    case 'LIGHTING_CURVE_SHIFT': {
      const lightingAnchors =
        'balanced key lighting, neutral cinematic contrast, studio photometric curve'
      const lightingNegatives =
        'blown out highlights, crushed shadows, harsh clipping, severe tint, uneven exposure'

      positive = `${positive}, ${lightingAnchors}`
      negative = `${negative}, ${lightingNegatives}`
      tokensAdded.push(lightingAnchors, lightingNegatives)
      break
    }

    case 'ANATOMICAL_COLLAPSE': {
      const anatomyAnchors =
        'anatomically correct human structure, symmetric facial features, fully formed hands and fingers'
      const anatomyNegatives =
        'bad anatomy, anatomical deformation, missing limbs, extra fingers, fused digits, warped face, asymmetric eyes, mutated hands'

      positive = `${positive}, ${anatomyAnchors}`
      negative = `${negative}, ${anatomyNegatives}`
      tokensAdded.push(anatomyAnchors, anatomyNegatives)
      // Perturb seed to escape malformed anatomical basin
      seed = seed + 7919 * currentAttempt
      break
    }

    case 'CANON_INVARIANT_BREACH': {
      const anachronisms = auditReport.scanTrace.anachronismsDetected
      let anachronismNegatives = ''

      if (anachronisms.length > 0) {
        anachronismNegatives = anachronisms
          .map((item) => `${item}, modern ${item}`)
          .join(', ')
        negative = `${negative}, ${anachronismNegatives}`
        tokensAdded.push(anachronismNegatives)
      }

      if (auditReport.remediationDirective) {
        positive = `${positive}, ${auditReport.remediationDirective}`
        tokensAdded.push(auditReport.remediationDirective)
      }
      break
    }
  }

  // Apply deduplication and ceiling enforcement
  const cleanPositive = enforceTokenCeiling(deduplicateTokens(positive))
  const cleanNegative = enforceTokenCeiling(deduplicateTokens(negative))

  const diffSummary =
    tokensAdded.length > 0
      ? `Injected: ${tokensAdded.join(' | ')}`
      : `Seed perturbed to ${seed}, denoise adjusted to ${denoise}`

  console.log(
    `>> [SYNTHESIS:PATCH] Strategy '${classification}' applied for Attempt ${currentAttempt + 1}. ${diffSummary} [OK]`,
  )

  return {
    patchedPrompts: {
      positivePrompt: cleanPositive,
      negativePrompt: cleanNegative,
      seed,
      denoiseStrength: denoise,
      extraParameters: currentPrompts.extraParameters,
    },
    strategyApplied: classification,
    diffSummary,
    tokensAdded,
  }
}

import type { CandidatePlate, GauntletResult } from '../triage/driftGauntlet.js'
import type { ExecutionJob } from '../queue/fairQueue.js'
import type { EscalationDossier } from '../triage/circuitBreaker.js'
import {
  synthesizeRemediatedPrompt,
  type PromptPayload,
} from './promptSynthesizer.js'

export type RemediationOutcomeStatus =
  'APPROVED' | 'RETRY_SCHEDULED' | 'HALTED_BLOCKED' | 'FATAL_FORMAT_ERROR'

export interface RemediationOutcome {
  status: RemediationOutcomeStatus
  remediatedJob?: ExecutionJob
  dossier?: EscalationDossier
  diagnostic: string
}

export class RemediationEngine {
  /**
   * Evaluates gauntlet results and autonomously synthesizes a corrected task payload.
   */
  public evaluateAndRemediate(
    candidate: CandidatePlate,
    gauntletResult: GauntletResult,
    currentJob: ExecutionJob,
  ): RemediationOutcome {
    // 1. Clean Pass: No remediation required
    if (gauntletResult.passed) {
      console.log(
        `>> [REMEDIATE:PASS] Candidate '${candidate.candidateSha}' passed all gauntlet tiers [OK]`,
      )
      return {
        status: 'APPROVED',
        diagnostic: gauntletResult.diagnostic,
      }
    }

    // 2. Format Violation: Cannot be fixed via prompt engineering
    if (gauntletResult.terminalStage === 'TIER_1') {
      console.error(
        `>> [REMEDIATE:FATAL] Candidate '${candidate.candidateSha}' failed Tier 1 pixel/format checks [FAIL]`,
      )
      return {
        status: 'FATAL_FORMAT_ERROR',
        diagnostic: gauntletResult.diagnostic,
      }
    }

    // 3. Inspect Circuit Breaker Status
    const cb = gauntletResult.circuitBreaker
    if (
      cb &&
      (cb.status === 'CIRCUIT_BREAKER_TRIPPED' ||
        cb.status === 'DIVERGENT_STRUCTURAL_CONFLICT')
    ) {
      console.error(
        `>> [REMEDIATE:HALT] Circuit breaker engaged for task '${currentJob.taskId}' (${cb.status}) [HALT]`,
      )
      return {
        status: 'HALTED_BLOCKED',
        dossier: cb.dossier,
        diagnostic: `Circuit breaker tripped. Status: ${cb.status}. Trajectory: ${cb.trajectory}`,
      }
    }

    // 4. Autonomous Prompt Synthesis on ALLOW_CYCLE_RETRY
    if (!gauntletResult.auditReport) {
      return {
        status: 'HALTED_BLOCKED',
        diagnostic: 'Missing VlmAuditReport for remediation synthesis.',
      }
    }

    const rawPrompts: PromptPayload = {
      positivePrompt: currentJob.prompts?.positive || '',
      negativePrompt: currentJob.prompts?.negative || '',
      seed: currentJob.seeds?.[0] ?? 42,
      denoiseStrength: currentJob.prompts?.denoiseStrength ?? 1.0,
      extraParameters: currentJob.prompts?.extraParameters,
    }

    const patchResult = synthesizeRemediatedPrompt(
      rawPrompts,
      gauntletResult.auditReport,
      currentJob.attemptCount,
    )

    // Construct remediated job payload
    const nextAttempt = currentJob.attemptCount + 1
    const remediatedJob: ExecutionJob = {
      ...currentJob,
      attemptCount: nextAttempt,
      seeds: [patchResult.patchedPrompts.seed ?? currentJob.seeds[0] + 1],
      prompts: {
        ...currentJob.prompts,
        positive: patchResult.patchedPrompts.positivePrompt,
        negative: patchResult.patchedPrompts.negativePrompt,
        denoiseStrength: patchResult.patchedPrompts.denoiseStrength,
        lastRemediationDiff: patchResult.diffSummary,
        strategyApplied: patchResult.strategyApplied,
      },
    }

    console.log(
      `>> [REMEDIATE:CYCLE] Task '${currentJob.taskId}' scheduled for Attempt ${nextAttempt}/${currentJob.maxAttempts} [OK]`,
    )

    return {
      status: 'RETRY_SCHEDULED',
      remediatedJob,
      diagnostic: `Remediated via strategy '${patchResult.strategyApplied}'. ${patchResult.diffSummary}`,
    }
  }
}

import { FairQueue, type ExecutionJob } from '../queue/fairQueue.js'
import {
  createGenesisBlock,
  appendLedgerEntry,
  verifyLedgerIntegrity,
  type LedgerEntry,
} from '../ledger/cryptoLedger.js'
import {
  formatPromotionNotification,
  formatWatchdogAlert,
  formatDlqAlert,
  ChatOpsGateway,
} from '../telemetry/chatOpsGateway.js'
import { DriftGauntlet, type CandidatePlate } from '../triage/driftGauntlet.js'
import { RemediationEngine } from '../remediation/remediationEngine.js'
import type { AuditCycleRecord } from '../triage/circuitBreaker.js'

export class ShotCoordinatorDO {
  private fairQueue = new FairQueue()
  private activeJob: ExecutionJob | null = null
  private currentEpoch = 0
  private lastArtistId: string | null = null
  private ledgerChain: LedgerEntry[] = []
  private auditHistory: Map<string, AuditCycleRecord[]> = new Map()
  private driftGauntlet = new DriftGauntlet()
  private remediationEngine = new RemediationEngine()
  private chatOpsGateway = new ChatOpsGateway()

  constructor(
    private ctx: any,
    private env: any,
  ) {
    this.ctx.blockConcurrencyWhile?.(async () => {
      const queueData = await this.ctx.storage.get('pending_queue')
      if (Array.isArray(queueData)) this.fairQueue = new FairQueue(queueData)

      const active = await this.ctx.storage.get('active_job')
      if (active) this.activeJob = active

      const epoch = await this.ctx.storage.get('current_epoch')
      if (typeof epoch === 'number') this.currentEpoch = epoch

      const chain = await this.ctx.storage.get('ledger_chain')
      if (Array.isArray(chain)) this.ledgerChain = chain

      const history = await this.ctx.storage.get('audit_history')
      if (history && typeof history === 'object') {
        this.auditHistory = new Map(Object.entries(history))
      }

      console.log(
        `>> [DO:BOOT] ShotCoordinatorDO rehydrated. Epoch: ${this.currentEpoch}, Queue Depth: ${this.fairQueue.size()} [OK]`,
      )
    })
  }

  async alarm(): Promise<void> {
    console.warn(
      `>> [WATCHDOG:TRIP] Lease timeout for task '${this.activeJob?.taskId || 'NONE'}' [ALERT]`,
    )
    if (!this.activeJob) {
      await this.ctx.storage.deleteAlarm()
      return
    }

    const task = this.activeJob
    task.attemptCount += 1
    this.currentEpoch += 1

    if (task.attemptCount < task.maxAttempts) {
      this.fairQueue.requeue(task)
      this.activeJob = null
      this.ledgerChain = await appendLedgerEntry(
        this.ledgerChain,
        'WATCHDOG_TIMEOUT_REQUEUE',
        {
          taskId: task.taskId,
          attempt: task.attemptCount,
          newEpoch: this.currentEpoch,
        },
      )
    } else {
      this.activeJob = null
      this.ledgerChain = await appendLedgerEntry(
        this.ledgerChain,
        'CIRCUIT_BREAKER_DLQ',
        {
          taskId: task.taskId,
          attemptCount: task.attemptCount,
        },
      )
      if (this.env?.CHATOPS_WEBHOOK_URL) {
        const dlqAlert = formatDlqAlert(
          task.taskId,
          task.attemptCount,
          'MAX_ATTEMPTS_EXHAUSTED',
        )
        this.chatOpsGateway
          .dispatchAlert(this.env.CHATOPS_WEBHOOK_URL, dlqAlert)
          .catch(() => {})
      }
    }

    await this.ctx.storage.deleteAlarm()
    await this.persistState()
  }

  async fetch(request: Request): Promise<Response> {
    const url = new URL(request.url)

    try {
      // Task Enqueue Route
      if (request.method === 'POST' && url.pathname.endsWith('/enqueue')) {
        const body = (await request.json().catch(() => ({}))) as any
        const {
          taskId,
          artistId,
          idempotencyKey,
          workflowTemplate = 'default.json',
          prompts = {},
          seeds = [42],
          maxAttempts = 3,
        } = body

        const job: ExecutionJob = {
          taskId,
          artistId,
          idempotencyKey,
          workflowTemplate,
          prompts,
          seeds,
          enqueuedAt: Date.now(),
          attemptCount: 0,
          maxAttempts,
        }

        const enqueued = this.fairQueue.enqueue(job)
        if (!enqueued) {
          return new Response(JSON.stringify({ error: 'DUPLICATE_TASK' }), {
            status: 409,
          })
        }

        if (this.ledgerChain.length === 0) {
          this.ledgerChain = [
            await createGenesisBlock(taskId, { enqueuedAt: Date.now() }),
          ]
        } else {
          this.ledgerChain = await appendLedgerEntry(
            this.ledgerChain,
            'TASK_ENQUEUED',
            { taskId, artistId },
          )
        }

        await this.persistState()
        return new Response(
          JSON.stringify({ ok: true, taskId, position: this.fairQueue.size() }),
          { status: 200 },
        )
      }

      // Lease Claim Route
      if (request.method === 'POST' && url.pathname.endsWith('/leases/claim')) {
        if (this.activeJob !== null) {
          return new Response(JSON.stringify({ ok: false, busy: true }), {
            status: 200,
          })
        }

        const job = this.fairQueue.dequeueNextFair(this.lastArtistId)
        if (!job) return new Response(null, { status: 204 })

        this.currentEpoch += 1
        this.activeJob = job
        this.lastArtistId = job.artistId

        this.ledgerChain = await appendLedgerEntry(
          this.ledgerChain,
          'LEASE_CLAIMED',
          {
            taskId: job.taskId,
            epoch: this.currentEpoch,
          },
        )

        await this.ctx.storage.setAlarm(Date.now() + 30_000)
        await this.persistState()

        return new Response(
          JSON.stringify({
            ok: true,
            taskId: job.taskId,
            epoch: this.currentEpoch,
            prompts: job.prompts,
            seeds: job.seeds,
          }),
          { status: 200 },
        )
      }

      // Autonomous Drift Triage & Remediation Gate
      if (
        request.method === 'POST' &&
        url.pathname.endsWith('/tasks/triage-and-remediate')
      ) {
        const body = (await request.json().catch(() => ({}))) as any
        const { candidate, vlmRawOutput } = body as {
          candidate: CandidatePlate
          vlmRawOutput?: string
        }

        if (!this.activeJob || this.activeJob.taskId !== candidate.taskId) {
          return new Response(JSON.stringify({ error: 'TASK_NOT_ACTIVE' }), {
            status: 404,
          })
        }

        const taskHistory = this.auditHistory.get(candidate.taskId) || []
        const gauntletResult = await this.driftGauntlet.evaluate(
          candidate,
          taskHistory,
          vlmRawOutput ? async () => vlmRawOutput : undefined,
        )

        if (gauntletResult.auditReport) {
          taskHistory.push({
            attempt: this.activeJob.attemptCount + 1,
            classification: gauntletResult.auditReport.classification,
            errorTokens:
              gauntletResult.auditReport.scanTrace.anachronismsDetected,
            timestampMs: Date.now(),
          })
          this.auditHistory.set(candidate.taskId, taskHistory)
        }

        // Autonomous Remediation Evaluation
        const outcome = this.remediationEngine.evaluateAndRemediate(
          candidate,
          gauntletResult,
          this.activeJob,
        )

        if (outcome.status === 'APPROVED') {
          // Clean Promotion
          await this.ctx.storage.deleteAlarm()
          const canonicalKey = `canonical/renders/${this.activeJob.taskId}/${candidate.candidateSha}.mp4`
          this.ledgerChain = await appendLedgerEntry(
            this.ledgerChain,
            'ARTIFACT_PROMOTED',
            { canonicalKey, candidateSha: candidate.candidateSha },
          )
          this.activeJob = null
          await this.persistState()

          return new Response(
            JSON.stringify({ ok: true, promoted: true, canonicalKey }),
            { status: 200 },
          )
        }

        if (outcome.status === 'RETRY_SCHEDULED' && outcome.remediatedJob) {
          // Autonomous Re-enqueue with Patched Prompts
          this.currentEpoch += 1
          this.fairQueue.requeue(outcome.remediatedJob)
          this.ledgerChain = await appendLedgerEntry(
            this.ledgerChain,
            'AUTONOMOUS_REMEDIATION_REQUEUE',
            {
              taskId: outcome.remediatedJob.taskId,
              attemptCount: outcome.remediatedJob.attemptCount,
              diff: outcome.remediatedJob.prompts?.lastRemediationDiff,
            },
          )

          this.activeJob = null
          await this.ctx.storage.deleteAlarm()
          await this.persistState()

          return new Response(
            JSON.stringify({
              ok: true,
              status: 'RETRY_SCHEDULED',
              diagnostic: outcome.diagnostic,
            }),
            { status: 200 },
          )
        }

        // Circuit Breaker Tripped / Halted
        this.ledgerChain = await appendLedgerEntry(
          this.ledgerChain,
          'CIRCUIT_BREAKER_HALT',
          {
            taskId: this.activeJob.taskId,
            diagnostic: outcome.diagnostic,
          },
        )

        if (this.env?.CHATOPS_WEBHOOK_URL && outcome.dossier) {
          const alert = formatDlqAlert(
            this.activeJob.taskId,
            outcome.dossier.exhaustedAttempts,
            outcome.dossier.contradictionSummary,
          )
          this.chatOpsGateway
            .dispatchAlert(this.env.CHATOPS_WEBHOOK_URL, alert)
            .catch(() => {})
        }

        this.activeJob = null
        await this.ctx.storage.deleteAlarm()
        await this.persistState()

        return new Response(
          JSON.stringify({
            ok: false,
            status: 'HALTED_BLOCKED',
            diagnostic: outcome.diagnostic,
            dossier: outcome.dossier,
          }),
          { status: 200 },
        )
      }

      return new Response('NOT_FOUND', { status: 404 })
    } catch (err: any) {
      console.error(`>> [DO:ERR] ${err.message}`)
      return new Response(JSON.stringify({ error: err.message }), {
        status: 500,
      })
    }
  }

  private async persistState(): Promise<void> {
    await this.ctx.storage.put('pending_queue', this.fairQueue.toArray())
    await this.ctx.storage.put('active_job', this.activeJob)
    await this.ctx.storage.put('current_epoch', this.currentEpoch)
    await this.ctx.storage.put('ledger_chain', this.ledgerChain)
    await this.ctx.storage.put(
      'audit_history',
      Object.fromEntries(this.auditHistory),
    )
  }
}
