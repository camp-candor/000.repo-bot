3. **DEPENDENCY PURITY:** Zero third-party scheduling, cron, or process

   Node.js/TypeScript built-ins.
4. **PURE 7-BIT ASCII TELEMETRY:** Zero multi-byte UTF-8 emojis across all
   source code, comments, log strings, and test descriptions. Enforce pure 7-bit
   ASCII tokens (`>>`, `[OK]`, `[FAIL]`, `::`, `[WATCHDOG]`, `[DISARM]`,
   `[ABORT]`, `[RACE_GUARD]`, `[TERMINAL]`).
5. **HARDWARE ALARM DISARM LAW:** Any manual `ABORT` or `OVERRIDE` intervention
   that extracts a task from active execution MUST synchronously execute
   `ctx.storage.deleteAlarm()`. Failing to clear the hardware alarm allows the
   Durable Object to wake up autonomously after the lease window expires and
   erroneously push the neutralized task into the Dead Letter Queue (DLQ).
6. **RACE CONDITION PREVENTION LAW:** If the edge isolate event loop schedules
   the `alarm()` handler concurrently with an operator's `ABORT` request, the
   `alarm()` method must evaluate the `fsmState` strictly. If
   `fsmState === 'ABORTED'`, the alarm must immediately return without modifying
   the queue, ledger, or attempt budget.

### II. ARCHITECTURAL REQUIREMENTS

#### 1. Hardware Watchdog Controller (`apps/worker/src/lifecycle/watchdogController.ts`)

- **Controller Model (`WatchdogController`):**
- Wraps the native Durable Object storage alarm APIs to provide strongly-typed,
  logged lease management.
- `armWatchdog(ctx, taskId, timeoutMs = 30000): Promise<void>`: Sets the
  execution ceiling and logs the active lease.
- `disarmWatchdog(ctx, taskId): Promise<void>`: Safely deletes the alarm and
  logs the neutralization.
- `evaluateAlarm(activeJob, fsmState): WatchdogEvaluation`: Analyzes the state
  machine when the alarm fires to determine if it's a valid timeout, a race
  condition, or an empty trigger.

- **Evaluation Types (`WatchdogEvaluation`):**
- `'RETRY_REQUIRED'`: Job is active, `attemptCount < maxAttempts`.
- `'DLQ_REQUIRED'`: Job is active, `attemptCount >= maxAttempts`.
- `'IGNORE_ABORTED'`: Race condition detected (`fsmState === 'ABORTED'`).
- `'IGNORE_EMPTY'`: Alarm fired but `activeJob` is null.

#### 2. Hard Task Abort Protocol Integration (`apps/worker/src/objects/ShotCoordinatorDO.ts`)

- **Command Mutation (`handleChatOpsCommand('ABORT')`):**
- Executes `WatchdogController.disarmWatchdog(this.ctx, cmd.taskId)`.
- Transitions `this.fsmState = 'ABORTED'`.
- Nullifies `this.activeJob`.
- Appends immutable `CHATOPS_TASK_ABORTED` block to `ledgerChain`.
- Safely ignores subsequent timeout evaluations for this generation cycle.

- **Alarm Handler (`async alarm()`):**
- Invokes `WatchdogController.evaluateAlarm(this.activeJob, this.fsmState)`.
- If `IGNORE_ABORTED` or `IGNORE_EMPTY`, returns immediately without mutating
  state.
- If `RETRY_REQUIRED` or `DLQ_REQUIRED`, processes the timeout according to the
  progressive escalation budget.

#### 3. Automated Vitest Verification Battery (`apps/worker/test/unit/watchdogInterruption.test.ts`)

- Verify `armWatchdog` correctly schedules the `setAlarm` future timestamp.
- Verify `disarmWatchdog` correctly invokes `deleteAlarm`.
- Verify `evaluateAlarm` detects race conditions and returns `IGNORE_ABORTED`
  when the state machine is locked.
- Verify `ShotCoordinatorDO` processes `ABORT`, clears the active job, and
  prevents DLQ insertion.
- Verify the `alarm()` handler safely drops out of execution if it fires
  immediately after a manual abort.

```typescript
import type { ExecutionJob } from '../queue/fairQueue.js'

export type WatchdogEvaluation =
  'RETRY_REQUIRED' | 'DLQ_REQUIRED' | 'IGNORE_ABORTED' | 'IGNORE_EMPTY'

export class WatchdogController {
  /**
   * Arms the hardware alarm to enforce a strict execution lease ceiling.
   */
  public static async armWatchdog(
    ctx: any,
    taskId: string,
    timeoutMs = 30000,
  ): Promise<void> {
    const triggerTime = Date.now() + timeoutMs
    await ctx.storage.setAlarm(triggerTime)
    console.log(
      `>> [WATCHDOG:ARMED] Execution lease armed for '${taskId}'. Ceiling: ${timeoutMs}ms [OK]`,
    )
  }

  /**
   * Disarms the hardware alarm, neutralizing the watchdog timer.
   */
  public static async disarmWatchdog(ctx: any, taskId: string): Promise<void> {
    await ctx.storage.deleteAlarm()
    console.log(
      `>> [WATCHDOG:DISARM] Execution lease disarmed for '${taskId}' [OK]`,
    )
  }

  /**
   * Evaluates the active state machine when an alarm fires to prevent race conditions.
   */
  public static evaluateAlarm(
    activeJob: ExecutionJob | null,
    fsmState: string,
  ): WatchdogEvaluation {
    if (!activeJob) {
      console.log(
        '>> [WATCHDOG:EVAL] Alarm fired but activeJob is null [IGNORE_EMPTY]',
      )
      return 'IGNORE_EMPTY'
    }

    if (fsmState === 'ABORTED') {
      console.warn(
        `>> [WATCHDOG:RACE_GUARD] Alarm fired for aborted task '${activeJob.taskId}'. Neutralizing execution [IGNORE_ABORTED]`,
      )
      return 'IGNORE_ABORTED'
    }

    if (activeJob.attemptCount + 1 < activeJob.maxAttempts) {
      console.warn(
        `>> [WATCHDOG:TRIP] Lease timeout for task '${activeJob.taskId}'. Escalation required [RETRY_REQUIRED]`,
      )
      return 'RETRY_REQUIRED'
    }

    console.error(
      `>> [WATCHDOG:FATAL] Attempt budget exhausted for task '${activeJob.taskId}'. DLQ insertion required [DLQ_REQUIRED]`,
    )
    return 'DLQ_REQUIRED'
  }
}
```

#### 2. Update `apps/worker/src/objects/ShotCoordinatorDO.ts`

```typescript
import { FairQueue, type ExecutionJob } from '../queue/fairQueue.js'
import {
  createGenesisBlock,
  appendLedgerEntry,
  type LedgerEntry,
} from '../ledger/cryptoLedger.js'
import type { ChatOpsCommand } from '../telemetry/chatOpsRouter.js'
import { WatchdogController } from '../lifecycle/watchdogController.js'

export class ShotCoordinatorDO {
  private fairQueue = new FairQueue()
  private activeJob: ExecutionJob | null = null
  private currentEpoch = 0
  private fsmState = 'PENDING'
  private ledgerChain: LedgerEntry[] = []

  constructor(
    private ctx: any,
    private env: any,
  ) {
    this.ctx.blockConcurrencyWhile?.(async () => {
      const queueData = await this.ctx.storage.get('pending_queue')
      if (Array.isArray(queueData)) this.fairQueue = new FairQueue(queueData)

      const active = await this.ctx.storage.get('active_job')
      if (active) this.activeJob = active

      const epoch = await this.ctx.storage.get('current_epoch')
      if (typeof epoch === 'number') this.currentEpoch = epoch

      const state = await this.ctx.storage.get('fsm_state')
      if (typeof state === 'string') this.fsmState = state

      const chain = await this.ctx.storage.get('ledger_chain')
      if (Array.isArray(chain)) this.ledgerChain = chain

      console.log(
        `>> [DO:BOOT] ShotCoordinatorDO loaded. State: ${this.fsmState}, Epoch: ${this.currentEpoch} [OK]`,
      )
    })
  }

  /**
   * Hardware alarm handler triggered by the Cloudflare Workers runtime.
   */
  async alarm(): Promise<void> {
    const evaluation = WatchdogController.evaluateAlarm(
      this.activeJob,
      this.fsmState,
    )

    if (evaluation === 'IGNORE_EMPTY' || evaluation === 'IGNORE_ABORTED') {
      await this.ctx.storage.deleteAlarm()
      return
    }

    const task = this.activeJob!
    task.attemptCount += 1
    this.currentEpoch += 1

    if (evaluation === 'RETRY_REQUIRED') {
      this.fsmState = 'RETRYING'
      this.fairQueue.requeue(task)
      this.activeJob = null
      this.ledgerChain = await appendLedgerEntry(
        this.ledgerChain,
        'WATCHDOG_TIMEOUT_REQUEUE',
        {
          taskId: task.taskId,
          attempt: task.attemptCount,
          newEpoch: this.currentEpoch,
        },
      )
    } else if (evaluation === 'DLQ_REQUIRED') {
      this.fsmState = 'DLQ'
      this.activeJob = null
      this.ledgerChain = await appendLedgerEntry(
        this.ledgerChain,
        'CIRCUIT_BREAKER_DLQ',
        {
          taskId: task.taskId,
          attemptCount: task.attemptCount,
        },
      )
    }

    await this.ctx.storage.deleteAlarm()
    await this.persistState()
  }

  async fetch(request: Request): Promise<Response> {
    const url = new URL(request.url)

    try {
      if (
        request.method === 'POST' &&
        url.pathname.endsWith('/chatops/command')
      ) {
        const cmd = (await request.json().catch(() => ({}))) as ChatOpsCommand
        return await this.handleChatOpsCommand(cmd)
      }

      if (request.method === 'POST' && url.pathname.endsWith('/leases/claim')) {
        if (this.activeJob !== null) {
          return new Response(JSON.stringify({ ok: false, busy: true }), {
            status: 200,
          })
        }

        const job = this.fairQueue.dequeueNextFair(null)
        if (!job) return new Response(null, { status: 204 })

        this.currentEpoch += 1
        this.activeJob = job
        this.fsmState = 'RUNNING'

        this.ledgerChain = await appendLedgerEntry(
          this.ledgerChain,
          'LEASE_CLAIMED',
          {
            taskId: job.taskId,
            epoch: this.currentEpoch,
          },
        )

        // Arm the watchdog lease ceiling
        await WatchdogController.armWatchdog(this.ctx, job.taskId, 30_000)
        await this.persistState()

        return new Response(
          JSON.stringify({
            ok: true,
            taskId: job.taskId,
            epoch: this.currentEpoch,
            prompts: job.prompts,
            seeds: job.seeds,
          }),
          { status: 200 },
        )
      }

      return new Response('NOT_FOUND', { status: 404 })
    } catch (err: any) {
      console.error(`>> [DO:ERR] ${err.message}`)
      return new Response(JSON.stringify({ error: err.message }), {
        status: 500,
      })
    }
  }

  /**
   * Executes manual operator state mutations, handling hard aborts and watchdog disarming.
   */
  private async handleChatOpsCommand(cmd: ChatOpsCommand): Promise<Response> {
    if (!cmd.taskId) {
      return new Response(JSON.stringify({ error: 'MISSING_TASK_ID' }), {
        status: 400,
      })
    }

    switch (cmd.action) {
      case 'ABORT': {
        // 1. Hardware alarm disarm
        await WatchdogController.disarmWatchdog(this.ctx, cmd.taskId)

        // 2. Terminal State Transition
        this.fsmState = 'ABORTED'

        // 3. Clear from queue if pending, or nullify active job
        this.fairQueue.remove(cmd.taskId)
        this.activeJob = null

        // 4. Asynchronous Ledger Commitment
        this.ledgerChain = await appendLedgerEntry(
          this.ledgerChain,
          'CHATOPS_TASK_ABORTED',
          {
            taskId: cmd.taskId,
            operatorId: cmd.operatorId,
          },
        )

        console.log(
          `>> [TERMINAL:ABORT] Task '${cmd.taskId}' permanently aborted by '${cmd.operatorId}'. Watchdog neutralized [HALT]`,
        )
        await this.persistState()

        return new Response(JSON.stringify({ ok: true, aborted: true }), {
          status: 200,
        })
      }

      default:
        return new Response(JSON.stringify({ error: 'UNRECOGNIZED_ACTION' }), {
          status: 400,
        })
    }
  }

  private async persistState(): Promise<void> {
    await this.ctx.storage.put('pending_queue', this.fairQueue.toArray())
    await this.ctx.storage.put('active_job', this.activeJob)
    await this.ctx.storage.put('current_epoch', this.currentEpoch)
    await this.ctx.storage.put('fsm_state', this.fsmState)
    await this.ctx.storage.put('ledger_chain', this.ledgerChain)
  }
}
```
