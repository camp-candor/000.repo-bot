   on native JavaScript arrays, Maps, and standard Cloudflare Durable Object
   `ctx.storage`.
4. **PURE 7-BIT ASCII TELEMETRY:** Zero multi-byte UTF-8 emojis across all
   source code, comments, log strings, and test descriptions. Enforce pure 7-bit
   ASCII tokens (`>>`, `[OK]`, `[FAIL]`, `::`, `[MUTATION]`, `[EPOCH_FENCE]`,
   `[ZOMBIE]`, `[DLQ_EXTRACT]`, `[QUEUE]`).
5. **MONOTONIC EPOCH FENCING LAW:** Following the Generative Production
   Pipeline, any manual operator intervention (`OVERRIDE` or `RETRY`) MUST
   increment the task's active epoch ($N \to N+1$). This creates an impenetrable
   fence: if a remote GPU runner subsequently attempts to submit a completed
   artifact using an outdated epoch $N$, the Durable Object must immediately
   reject it with an `HTTP 409 Conflict` (`STALE_EPOCH_ZOMBIE`), ensuring stale
   in-flight renders can never corrupt the canonical manifest.
6. **ATTEMPT BUDGET RESET LAW:** When a task is manually intervened upon, it
   must be extracted from the Dead Letter Queue (`DLQ`) or `BLOCKED` state. Its
   `attemptCount` must be strictly reset to `0`, restoring its full progressive
   escalation budget.
7. **PRIORITY FAIR QUEUE RE-INSERTION:** Mutated jobs resulting from an operator
   `OVERRIDE` must be pushed back into the task queue. The queue must ensure
   round-robin fairness across `artistId` to prevent a single artist from
   starving the compute foundry.

### II. ARCHITECTURAL REQUIREMENTS

#### 1. Fair Queue Engine (`apps/worker/src/queue/fairQueue.ts`)

- **Job Model (`ExecutionJob`):**
- `taskId`: String identifier.
- `artistId`: Identifier of the submitting operator.
- `idempotencyKey`: Unique deduplication key.
- `workflowTemplate`: ComfyUI JSON schema reference.
- `prompts`: Dictionary containing `positive`, `negative`, `denoiseStrength`,
  etc.
- `seeds`: Array of integer seeds.
- `enqueuedAt`: Timestamp.
- `attemptCount`: Cycle tracking integer.
- `maxAttempts`: Ceiling threshold.

- **Engine Methods (`FairQueue`):**
- `enqueue(job: ExecutionJob): boolean`: Adds task to the back of the queue.
  Rejects duplicates.
- `requeuePriority(job: ExecutionJob): void`: Inserts a mutated job at the
  _front_ of the queue for immediate execution, grouped fairly by artist.
- `dequeueNextFair(lastArtistId: string | null): ExecutionJob | null`: Executes
  round-robin selection. Finds the first task belonging to an artist _other_
  than `lastArtistId`. If none exists, falls back to standard FIFO.
- `remove(taskId: string): boolean`: Purges a job from the queue if aborted.

#### 2. State Machine Mutation Integration (`apps/worker/src/objects/ShotCoordinatorDO.ts`)

- **ChatOps Command Mutation (`handleChatOpsCommand`):**
- On `OVERRIDE` or `RETRY`:
- Disarm hardware watchdog alarm (`ctx.storage.deleteAlarm()`).
- Increment `currentEpoch += 1`.
- Set `fsmState = 'PENDING'`.
- Reset `attemptCount = 0`.
- Apply payload mutations (e.g., replace `positivePrompt`, override `seed`).
- Extract from `activeJob` and push to `fairQueue.requeuePriority()`.
- Append `CHATOPS_MANUAL_OVERRIDE` to `ledgerChain`.

- **Zombie Lease Rejection (`POST /tasks/complete`):**
- Extracts `epoch` from the incoming request payload.
- Enforces strict equality:
  `if (incomingEpoch !== this.currentEpoch) { throw STALE_EPOCH_ZOMBIE }`.

#### 3. Automated Vitest Verification Battery (`apps/worker/test/unit/stateMachineMutation.test.ts`)

- Verify `OVERRIDE` resets `attemptCount` to 0 and transitions `DLQ` tasks back

- Verify `OVERRIDE` increments the `currentEpoch` monotonically.
- Verify late-arriving artifact submissions using older epochs are rejected

- Verify `FairQueue.dequeueNextFair` cycles through `artistId` values without

```typescript
export interface ExecutionJob {
  taskId: string
  artistId: string
  idempotencyKey: string
  workflowTemplate: string
  prompts: {
    positive?: string
    negative?: string
    denoiseStrength?: number
    [key: string]: any
  }
  seeds: number[]
  enqueuedAt: number
  attemptCount: number
  maxAttempts: number
}

export class FairQueue {
  private queue: ExecutionJob[] = []

  constructor(initialState: ExecutionJob[] = []) {
    this.queue = [...initialState]
  }

  /**
   * Enqueues a job at the back of the line. Returns false if duplicate taskId.
   */
  public enqueue(job: ExecutionJob): boolean {
    if (this.queue.some((j) => j.taskId === job.taskId)) {
      return false
    }
    this.queue.push(job)
    return true
  }

  /**
   * Inserts a mutated or intervened job at the front of the queue for priority processing.
   */
  public requeuePriority(job: ExecutionJob): void {
    this.remove(job.taskId)
    this.queue.unshift(job)
  }

  /**
   * Standard requeue at the back (e.g., automated progressive escalation retry).
   */
  public requeue(job: ExecutionJob): void {
    this.remove(job.taskId)
    this.queue.push(job)
  }

  /**
   * Removes a specific task from the queue by ID.
   */
  public remove(taskId: string): boolean {
    const initialLength = this.queue.length
    this.queue = this.queue.filter((j) => j.taskId !== taskId)
    return this.queue.length < initialLength
  }

  /**
   * Dequeues the next job, prioritizing round-robin fairness across artists.
   */
  public dequeueNextFair(lastArtistId: string | null): ExecutionJob | null {
    if (this.queue.length === 0) {
      return null
    }

    // Attempt to find a task from a different artist to prevent starvation
    if (lastArtistId) {
      const fairIndex = this.queue.findIndex((j) => j.artistId !== lastArtistId)
      if (fairIndex !== -1) {
        const [fairJob] = this.queue.splice(fairIndex, 1)
        return fairJob
      }
    }

    // Fallback to strict FIFO if only one artist is queued
    return this.queue.shift() || null
  }

  public size(): number {
    return this.queue.length
  }

  public toArray(): ExecutionJob[] {
    return [...this.queue]
  }
}
```

```typescript
import { FairQueue, type ExecutionJob } from '../queue/fairQueue.js'
import {
  createGenesisBlock,
  appendLedgerEntry,
  type LedgerEntry,
} from '../ledger/cryptoLedger.js'
import type { ChatOpsCommand } from '../telemetry/chatOpsRouter.js'

export class ShotCoordinatorDO {
  private fairQueue = new FairQueue()
  private activeJob: ExecutionJob | null = null
  private currentEpoch = 0
  private lastArtistId: string | null = null
  private fsmState = 'PENDING'
  private ledgerChain: LedgerEntry[] = []

  constructor(
    private ctx: any,
    private env: any,
  ) {
    this.ctx.blockConcurrencyWhile?.(async () => {
      const queueData = await this.ctx.storage.get('pending_queue')
      if (Array.isArray(queueData)) this.fairQueue = new FairQueue(queueData)

      const active = await this.ctx.storage.get('active_job')
      if (active) this.activeJob = active

      const epoch = await this.ctx.storage.get('current_epoch')
      if (typeof epoch === 'number') this.currentEpoch = epoch

      const state = await this.ctx.storage.get('fsm_state')
      if (typeof state === 'string') this.fsmState = state

      const chain = await this.ctx.storage.get('ledger_chain')
      if (Array.isArray(chain)) this.ledgerChain = chain

      console.log(
        `>> [DO:BOOT] ShotCoordinatorDO loaded. State: ${this.fsmState}, Epoch: ${this.currentEpoch} [OK]`,
      )
    })
  }

  async fetch(request: Request): Promise<Response> {
    const url = new URL(request.url)

    try {
      // Artifact Completion Route (Zombie Guard)
      if (
        request.method === 'POST' &&
        url.pathname.endsWith('/tasks/complete')
      ) {
        const body = (await request.json().catch(() => ({}))) as any
        const { epoch, stagingKey, sha256 } = body

        if (!this.activeJob) {
          return new Response(JSON.stringify({ error: 'NO_ACTIVE_TASK' }), {
            status: 404,
          })
        }

        // RULE: Monotonic Epoch Fencing Law
        // Prevents old renders completed by zombie hardware from committing
        if (epoch !== this.currentEpoch) {
          console.warn(
            `>> [EPOCH_FENCE:BLOCK] Rejected zombie submission. Expected Epoch ${this.currentEpoch}, got ${epoch} [ZOMBIE]`,
          )
          return new Response(
            JSON.stringify({
              error: 'STALE_EPOCH_ZOMBIE',
              message: `Presented epoch ${epoch} is stale. Active fence is ${this.currentEpoch}`,
            }),
            { status: 409, headers: { 'Content-Type': 'application/json' } },
          )
        }

        this.fsmState = 'VERIFYING'
        await this.ctx.storage.deleteAlarm()

        const canonicalKey = `canonical/renders/${this.activeJob.taskId}/${sha256}.mp4`
        this.ledgerChain = await appendLedgerEntry(
          this.ledgerChain,
          'ARTIFACT_PROMOTED',
          {
            canonicalKey,
            sha256,
            epoch: this.currentEpoch,
          },
        )

        this.activeJob = null
        await this.persistState()

        return new Response(
          JSON.stringify({ ok: true, promoted: true, canonicalKey }),
          { status: 200 },
        )
      }

      // Headless Command Mutation Ingress
      if (
        request.method === 'POST' &&
        url.pathname.endsWith('/chatops/command')
      ) {
        // In production, HMAC validation occurs here via chatOpsAuth.ts
        const cmd = (await request.json().catch(() => ({}))) as ChatOpsCommand
        return await this.handleChatOpsCommand(cmd)
      }

      return new Response('NOT_FOUND', { status: 404 })
    } catch (err: any) {
      console.error(`>> [DO:ERR] ${err.message}`)
      return new Response(JSON.stringify({ error: err.message }), {
        status: 500,
      })
    }
  }

  /**
   * Executes manual operator state mutations, handling epoch bumps and DLQ extraction.
   */
  private async handleChatOpsCommand(cmd: ChatOpsCommand): Promise<Response> {
    if (!cmd.taskId) {
      return new Response(JSON.stringify({ error: 'MISSING_TASK_ID' }), {
        status: 400,
      })
    }

    switch (cmd.action) {
      case 'OVERRIDE': {
        // 1. Hardware alarm disarm
        await this.ctx.storage.deleteAlarm()

        // 2. Monotonic Epoch Bump
        this.currentEpoch += 1

        // 3. DLQ Extraction & Attempt Reset
        this.fsmState = 'PENDING'

        const targetJob: ExecutionJob = this.activeJob || {
          taskId: cmd.taskId,
          artistId: 'operator_override',
          idempotencyKey: `idemp-${Date.now()}`,
          workflowTemplate: 'default.json',
          prompts: {},
          seeds: [42],
          enqueuedAt: Date.now(),
          attemptCount: 0,
          maxAttempts: 3,
        }

        targetJob.attemptCount = 0 // Fresh attempt budget

        // 4. Payload Mutation
        if (cmd.positivePrompt) targetJob.prompts.positive = cmd.positivePrompt
        if (cmd.negativePrompt) targetJob.prompts.negative = cmd.negativePrompt
        if (cmd.seed !== undefined) targetJob.seeds = [cmd.seed]
        if (cmd.denoiseStrength !== undefined)
          targetJob.prompts.denoiseStrength = cmd.denoiseStrength

        // 5. Priority Re-insertion
        this.fairQueue.requeuePriority(targetJob)
        this.activeJob = null

        const diff = `Prompt updated to: "${targetJob.prompts.positive || 'SAME'}", Seed: ${targetJob.seeds[0]}`
        this.ledgerChain = await appendLedgerEntry(
          this.ledgerChain,
          'CHATOPS_MANUAL_OVERRIDE',
          {
            taskId: cmd.taskId,
            operatorId: cmd.operatorId,
            newEpoch: this.currentEpoch,
            diff,
          },
        )

        console.log(
          `>> [MUTATION:OVERRIDE] Task '${cmd.taskId}' bumped to Epoch ${this.currentEpoch}, extracted to PENDING [OK]`,
        )
        await this.persistState()

        return new Response(
          JSON.stringify({
            ok: true,
            overridden: true,
            epoch: this.currentEpoch,
          }),
          { status: 200 },
        )
      }

      case 'ABORT': {
        await this.ctx.storage.deleteAlarm()
        this.fsmState = 'ABORTED'

        // Clear from queue if it was pending
        this.fairQueue.remove(cmd.taskId)
        this.activeJob = null

        this.ledgerChain = await appendLedgerEntry(
          this.ledgerChain,
          'CHATOPS_TASK_ABORTED',
          {
            taskId: cmd.taskId,
            operatorId: cmd.operatorId,
          },
        )

        console.log(
          `>> [MUTATION:ABORT] Task '${cmd.taskId}' aborted by '${cmd.operatorId}' [HALT]`,
        )
        await this.persistState()

        return new Response(JSON.stringify({ ok: true, aborted: true }), {
          status: 200,
        })
      }

      default:
        return new Response(JSON.stringify({ error: 'UNRECOGNIZED_ACTION' }), {
          status: 400,
        })
    }
  }

  private async persistState(): Promise<void> {
    await this.ctx.storage.put('pending_queue', this.fairQueue.toArray())
    await this.ctx.storage.put('active_job', this.activeJob)
    await this.ctx.storage.put('current_epoch', this.currentEpoch)
    await this.ctx.storage.put('fsm_state', this.fsmState)
    await this.ctx.storage.put('ledger_chain', this.ledgerChain)
  }
}
```
