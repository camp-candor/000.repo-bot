### II. ARCHITECTURAL REQUIREMENTS

#### 1. Deterministic In-Memory Timer Scheduler (`apps/worker/src/objects/timerScheduler.ts`)

- **Timer Definition (`ScheduledTimer`):**
- `id: 'watchdog' | 'absolute_cap'`: Strict deterministic identifier per timer
  type to prevent unbounded array growth or timer stacking.

- `type: 'WATCHDOG' | 'ABSOLUTE_CAP'`: Discriminated timer type.

- `fireAt: number`: Millisecond timestamp when the alarm must fire.

- `epoch: number`: The monotonic epoch under which this timer was scheduled.

- `epochScoped: boolean`: If `true`, the timer is invalid and dropped if the DO
  epoch advances before it fires.

- **Pure Scheduler Utilities:**
- `scheduleTimer(timers, newTimer)`: Replaces any existing timer with the same
  `id`, appends the new timer, and returns an array sorted ascending by
  `fireAt`.

- `cancelTimer(timers, id)`: Removes the timer matching `id`.

- `getEarliestFireTime(timers)`: Returns the lowest `fireAt` timestamp or `null`
  if empty.

- `pollDueTimers(timers, now, currentEpoch)`: Partitions timers into
  `{ due: ScheduledTimer[], remaining: ScheduledTimer[] }`. Timers where
  `epochScoped === true` and `timer.epoch !== currentEpoch` are safely discarded
  without firing.

#### 2. Rolling Heartbeat & Time Extension Gate (`apps/worker/src/objects/ShotCoordinatorDO.ts`)

- **Rolling Window Policy:**
- When a lease is claimed and enters `RUNNING`, schedule `watchdog`
  (`now + 30_000ms`) and `absolute_cap` (`now + 900_000ms`).

- Arm the hardware storage alarm to the earliest due time (`now + 30_000ms`).

- **Heartbeat Verification (`POST /leases/heartbeat`):**
- Payload: `{ workerId: string, epoch: number }`.

- Token Validation: If `epoch !== this.currentEpoch`, immediately reject with
  `HTTP 409 Conflict: Stale Epoch`.

- State Validation: If `this.fsmState !== 'RUNNING'`, return
  `HTTP 409 Conflict: Invalid State`.

- Rolling Extension: Advance `leaseExpiresAt = now + 30_000ms`.

- Re-arm `watchdog` timer to `now + 30_000ms` (clamped so it cannot exceed
  `absolute_cap.fireAt`).

- Update `ctx.storage.setAlarm` to the new earliest due timestamp.

#### 3. Proactive Hardware Alarm Handler & Circuit Breaker (`alarm()`)

- **Wake-up & Evaluation:**
- When the Cloudflare hypervisor invokes `alarm()`, call
  `pollDueTimers(this.timers, now, this.currentEpoch)`.

- Process due timers in sequence.

- **Watchdog Expiration Trigger (`type === 'WATCHDOG'`):**
- If task is in `RUNNING` or `CLAIMED`:
- Log
  `>> [WATCHDOG:TRIP] Lease expired after missed heartbeats. Epoch: ${currentEpoch}`.

- Increment `attemptCount`.

- Circuit Breaker Rule: If `attemptCount >= maxAttempts` (3), transition to
  `DLQ`; otherwise transition to `RETRYING`.

- Advance monotonic epoch ($N \to N+1$) to fence out any partitioned worker.

- Purge worker-facing epoch-scoped timers.

- **Absolute Cap Expiration Trigger (`type === 'ABSOLUTE_CAP'`):**
- Log
  `>> [ABSOLUTE_CAP:TRIP] Task execution exceeded 15m maximum window. Tripping circuit breaker.`

- Transition task to `DLQ` or `ROLLING_BACK`, bump epoch ($N \to N+1$), and
  disarm all timers.

- **Re-Arm / Cleanup:**
- If remaining timers exist, call
  `ctx.storage.setAlarm(getEarliestFireTime(remaining))`.

- If no timers remain, call `ctx.storage.deleteAlarm()`.

#### 4. Automated Vitest Verification Battery (`apps/worker/test/unit/timeAuthorityWatchdog.test.ts`)

- Verify heartbeat rolls lease expiration by +30s and reschedules alarm.

- Verify stale epoch heartbeat is rejected with `HTTP 409 Conflict`.

- Verify 3-cycle circuit breaker trips task into `DLQ` when `attemptCount >= 3`.

```typescript
export type TimerType = 'WATCHDOG' | 'ABSOLUTE_CAP'
export type TimerId = 'watchdog' | 'absolute_cap'

export interface ScheduledTimer {
  id: TimerId
  type: TimerType
  fireAt: number
  epoch: number
  epochScoped: boolean
}

export interface PollResult {
  due: ScheduledTimer[]
  remaining: ScheduledTimer[]
}

/**
 * Schedules or replaces a timer by its deterministic ID and sorts ascending by fireAt.
 */
export function scheduleTimer(
  timers: ScheduledTimer[],
  newTimer: ScheduledTimer,
): ScheduledTimer[] {
  const filtered = timers.filter((t) => t.id !== newTimer.id)
  filtered.push(newTimer)
  return filtered.sort((a, b) => a.fireAt - b.fireAt)
}

/**
 * Cancels a timer by its deterministic ID.
 */
export function cancelTimer(
  timers: ScheduledTimer[],
  id: TimerId,
): ScheduledTimer[] {
  return timers.filter((t) => t.id !== id)
}

/**
 * Returns the earliest fire timestamp among active timers, or null if empty.
 */
export function getEarliestFireTime(timers: ScheduledTimer[]): number | null {
  if (timers.length === 0) return null
  return timers[0].fireAt
}

/**
 * Partitions timers into due and remaining. Drops stale epoch-scoped timers.
 */
export function pollDueTimers(
  timers: ScheduledTimer[],
  now: number,
  currentEpoch: number,
): PollResult {
  const due: ScheduledTimer[] = []
  const remaining: ScheduledTimer[] = []

  for (const timer of timers) {
    // Drop stale epoch-scoped timers
    if (timer.epochScoped && timer.epoch !== currentEpoch) {
      console.log(
        `>> [TIMER:DISCARD] Dropping stale ${timer.id} timer (Epoch ${timer.epoch} != ${currentEpoch}) [OK]`,
      )
      continue
    }

    if (timer.fireAt <= now) {
      due.push(timer)
    } else {
      remaining.push(timer)
    }
  }

  return { due, remaining: remaining.sort((a, b) => a.fireAt - b.fireAt) }
}
```

```typescript
import {
  evaluateFsmTransition,
  isRevokingEvent,
  isTerminalState,
  type TaskState,
  type TaskEvent,
  type TransitionContext,
} from '../fsm/transitions.js'
import {
  scheduleTimer,
  cancelTimer,
  getEarliestFireTime,
  pollDueTimers,
  type ScheduledTimer,
} from './timerScheduler.js'

export const WATCHDOG_WINDOW_MS = 30_000
export const MAX_EXECUTION_CAP_MS = 15 * 60_000 // 15 Minutes Hard Cap

export interface TaskRecord {
  taskId: string
  fsmState: TaskState
  currentEpoch: number
  leaseExpiresAt: number
  attemptCount: number
  maxAttempts: number
  activeWorkerId: string | null
  isHighRisk: boolean
  timers: ScheduledTimer[]
  updatedAt: number
}

export class ShotCoordinatorDO {
  private taskId = ''
  private fsmState: TaskState = 'PENDING'
  private currentEpoch = 0
  private leaseExpiresAt = 0
  private attemptCount = 0
  private maxAttempts = 3
  private activeWorkerId: string | null = null
  private isHighRisk = false
  private timers: ScheduledTimer[] = []
  private updatedAt = Date.now()

  constructor(
    private ctx: any,
    private env: any,
  ) {
    this.ctx.blockConcurrencyWhile?.(async () => {
      const record = await this.ctx.storage.get('task_record')
      if (record && typeof record === 'object') {
        this.taskId = record.taskId || ''
        this.fsmState = record.fsmState || 'PENDING'
        this.currentEpoch = Number(record.currentEpoch || 0)
        this.leaseExpiresAt = Number(record.leaseExpiresAt || 0)
        this.attemptCount = Number(record.attemptCount || 0)
        this.maxAttempts = Number(record.maxAttempts || 3)
        this.activeWorkerId = record.activeWorkerId || null
        this.isHighRisk = Boolean(record.isHighRisk)
        this.timers = Array.isArray(record.timers) ? record.timers : []
        this.updatedAt = Number(record.updatedAt || Date.now())
        console.log(
          `>> [DO:BOOT] Rehydrated task '${this.taskId}' (${this.fsmState}) Epoch: ${this.currentEpoch} [OK]`,
        )
      }
    })
  }

  /**
   * Unified State Choke Point & Timer Lifecycle Reconciler.
   */
  async applyTransition(
    event: TaskEvent,
    actor: { type: string; id: string; epoch?: number },
    payload?: any,
  ): Promise<TaskRecord> {
    const context: TransitionContext = {
      attemptCount: this.attemptCount,
      maxAttempts: this.maxAttempts,
      isHighRisk: this.isHighRisk,
    }

    const result = evaluateFsmTransition(this.fsmState, event, context)
    if (!result.isValid) {
      console.error(`>> [FSM:REJECT] ${result.error} [FAIL]`)
      throw new Error(result.error)
    }

    if (result.isTerminalNoOp) {
      return this.getSnapshot()
    }

    const previousState = this.fsmState
    const nextState = result.nextState

    if (previousState === nextState) {
      return this.getSnapshot()
    }

    const now = Date.now()

    // Monotonic Epoch Advancement
    if (
      event === 'CLAIM_LEASE' ||
      isRevokingEvent(event) ||
      event === 'RETRY'
    ) {
      this.currentEpoch += 1
      console.log(
        `>> [EPOCH:BUMP] Advanced epoch to ${this.currentEpoch} via '${event}' [OK]`,
      )
    }

    this.fsmState = nextState
    this.updatedAt = now

    if (event === 'CLAIM_LEASE') {
      this.attemptCount += 1
      this.activeWorkerId = actor.id || null
      this.leaseExpiresAt = now + WATCHDOG_WINDOW_MS
    }

    // Timer Lifecycle Reconciliation
    if (nextState === 'RUNNING') {
      this.timers = scheduleTimer(this.timers, {
        id: 'watchdog',
        type: 'WATCHDOG',
        fireAt: now + WATCHDOG_WINDOW_MS,
        epoch: this.currentEpoch,
        epochScoped: true,
      })
      this.timers = scheduleTimer(this.timers, {
        id: 'absolute_cap',
        type: 'ABSOLUTE_CAP',
        fireAt: now + MAX_EXECUTION_CAP_MS,
        epoch: this.currentEpoch,
        epochScoped: true,
      })
      await this.syncHardwareAlarm()
    } else if (previousState === 'RUNNING' && nextState !== 'RUNNING') {
      // Unconditional deletion of worker timers upon leaving RUNNING
      this.timers = cancelTimer(this.timers, 'watchdog')
      this.timers = cancelTimer(this.timers, 'absolute_cap')
      await this.syncHardwareAlarm()
    }

    if (isTerminalState(nextState)) {
      this.timers = []
      await this.ctx.storage.deleteAlarm()
      this.activeWorkerId = null
      this.leaseExpiresAt = 0
    }

    const snapshot = this.getSnapshot()
    await this.ctx.storage.put('task_record', snapshot)
    console.log(
      `>> [FSM:TRANSITION] '${previousState}' -> '${nextState}' via '${event}' (Epoch: ${this.currentEpoch}) [OK]`,
    )
    return snapshot
  }

  /**
   * Proactive Hardware Storage Alarm Callback.
   */
  async alarm(): Promise<void> {
    const now = Date.now()
    console.warn(
      `>> [ALARM:WAKE] Alarm fired for task '${this.taskId}' at ${now} [ALERT]`,
    )

    const { due, remaining } = pollDueTimers(
      this.timers,
      now,
      this.currentEpoch,
    )
    this.timers = remaining

    for (const timer of due) {
      if (timer.type === 'WATCHDOG') {
        if (this.fsmState === 'RUNNING' || this.fsmState === 'CLAIMED') {
          console.warn(
            `>> [WATCHDOG:EXPIRE] 30s heartbeat window expired for task '${this.taskId}' [ALERT]`,
          )
          await this.applyTransition('WATCHDOG_EXPIRE', {
            type: 'SYSTEM',
            id: 'WATCHDOG_ALARM',
          })
        }
      } else if (timer.type === 'ABSOLUTE_CAP') {
        if (this.fsmState === 'RUNNING') {
          console.error(
            `>> [ABSOLUTE_CAP:EXPIRE] 15m maximum execution cap exceeded for task '${this.taskId}' [FAIL]`,
          )
          await this.applyTransition('WATCHDOG_EXPIRE', {
            type: 'SYSTEM',
            id: 'ABSOLUTE_CAP_ALARM',
          })
        }
      }
    }

    await this.syncHardwareAlarm()
    await this.ctx.storage.put('task_record', this.getSnapshot())
  }

  /**
   * Synchronizes ctx.storage alarm with the earliest active timer.
   */
  private async syncHardwareAlarm(): Promise<void> {
    const earliest = getEarliestFireTime(this.timers)
    if (earliest !== null) {
      await this.ctx.storage.setAlarm(earliest)
      console.log(`>> [ALARM:SET] Storage alarm armed for ${earliest} [OK]`)
    } else {
      await this.ctx.storage.deleteAlarm()
      console.log(`>> [ALARM:CLEAR] All storage alarms disarmed [OK]`)
    }
  }

  /**
   * HTTP / RPC Interface.
   */
  async fetch(request: Request): Promise<Response> {
    const url = new URL(request.url)

    try {
      if (request.method === 'POST' && url.pathname.endsWith('/leases/claim')) {
        const body = (await request.json().catch(() => ({}))) as any
        const workerId = body.workerId || 'UNKNOWN_WORKER'

        if (this.fsmState !== 'PENDING') {
          return new Response(
            JSON.stringify({
              error: `TASK_UNAVAILABLE: State is '${this.fsmState}'`,
            }),
            { status: 409, headers: { 'Content-Type': 'application/json' } },
          )
        }

        if (!this.taskId) {
          this.taskId = body.taskId || 'task-default'
          this.isHighRisk = Boolean(body.isHighRisk)
        }

        const record = await this.applyTransition('CLAIM_LEASE', {
          type: 'WORKER',
          id: workerId,
        })

        return new Response(
          JSON.stringify({
            ok: true,
            taskId: record.taskId,
            epoch: record.currentEpoch,
            leaseExpiresAt: record.leaseExpiresAt,
            fsmState: record.fsmState,
          }),
          { status: 200, headers: { 'Content-Type': 'application/json' } },
        )
      }

      if (
        request.method === 'POST' &&
        url.pathname.endsWith('/leases/acknowledge')
      ) {
        const body = (await request.json().catch(() => ({}))) as any
        const { workerId, epoch } = body

        if (epoch !== this.currentEpoch) {
          return new Response(
            JSON.stringify({
              error: `STALE_EPOCH: Presented ${epoch}, Active ${this.currentEpoch}`,
            }),
            { status: 409, headers: { 'Content-Type': 'application/json' } },
          )
        }

        const record = await this.applyTransition('ACK_RUNNING', {
          type: 'WORKER',
          id: workerId,
        })

        return new Response(
          JSON.stringify({
            ok: true,
            fsmState: record.fsmState,
            epoch: record.currentEpoch,
          }),
          { status: 200, headers: { 'Content-Type': 'application/json' } },
        )
      }

      if (
        request.method === 'POST' &&
        url.pathname.endsWith('/leases/heartbeat')
      ) {
        const body = (await request.json().catch(() => ({}))) as any
        const { epoch } = body
        const now = Date.now()

        // 1. Monotonic Epoch Token Guard (Zombie Runner Defense)
        if (epoch !== this.currentEpoch) {
          console.warn(
            `>> [HEARTBEAT:REJECT] Stale Epoch ${epoch} != Active ${this.currentEpoch} [FAIL]`,
          )
          return new Response(
            JSON.stringify({
              error: `HTTP 409 Conflict: Stale Epoch ${epoch}. Active is ${this.currentEpoch}`,
            }),
            { status: 409, headers: { 'Content-Type': 'application/json' } },
          )
        }

        if (this.fsmState !== 'RUNNING') {
          return new Response(
            JSON.stringify({
              error: `INVALID_STATE: Task is in '${this.fsmState}', expected RUNNING`,
            }),
            { status: 409, headers: { 'Content-Type': 'application/json' } },
          )
        }

        // 2. Extend rolling lease window
        this.leaseExpiresAt = now + WATCHDOG_WINDOW_MS
        this.updatedAt = now

        // 3. Reschedule watchdog timer
        this.timers = scheduleTimer(this.timers, {
          id: 'watchdog',
          type: 'WATCHDOG',
          fireAt: this.leaseExpiresAt,
          epoch: this.currentEpoch,
          epochScoped: true,
        })

        await this.syncHardwareAlarm()
        await this.ctx.storage.put('task_record', this.getSnapshot())

        return new Response(
          JSON.stringify({
            ok: true,
            epoch: this.currentEpoch,
            leaseExpiresAt: this.leaseExpiresAt,
          }),
          { status: 200, headers: { 'Content-Type': 'application/json' } },
        )
      }

      if (
        request.method === 'POST' &&
        url.pathname.endsWith('/tasks/complete')
      ) {
        const body = (await request.json().catch(() => ({}))) as any
        const { workerId, epoch, payload } = body

        if (epoch !== this.currentEpoch) {
          return new Response(
            JSON.stringify({
              error: `HTTP 409 Conflict: Stale Epoch ${epoch}. Active is ${this.currentEpoch}`,
            }),
            { status: 409, headers: { 'Content-Type': 'application/json' } },
          )
        }

        const record = await this.applyTransition(
          'SUBMIT_VERIFICATION',
          { type: 'WORKER', id: workerId },
          payload,
        )

        return new Response(
          JSON.stringify({
            ok: true,
            fsmState: record.fsmState,
            epoch: record.currentEpoch,
          }),
          { status: 200, headers: { 'Content-Type': 'application/json' } },
        )
      }

      if (request.method === 'GET' && url.pathname.endsWith('/state')) {
        return new Response(JSON.stringify(this.getSnapshot()), {
          status: 200,
          headers: { 'Content-Type': 'application/json' },
        })
      }

      return new Response('NOT_FOUND', { status: 404 })
    } catch (err: any) {
      console.error(`>> [DO:ERROR] ${err.message || String(err)}`)
      return new Response(
        JSON.stringify({ error: err.message || 'INTERNAL_ERROR' }),
        {
          status: 500,
          headers: { 'Content-Type': 'application/json' },
        },
      )
    }
  }

  private getSnapshot(): TaskRecord {
    return {
      taskId: this.taskId,
      fsmState: this.fsmState,
      currentEpoch: this.currentEpoch,
      leaseExpiresAt: this.leaseExpiresAt,
      attemptCount: this.attemptCount,
      maxAttempts: this.maxAttempts,
      activeWorkerId: this.activeWorkerId,
      isHighRisk: this.isHighRisk,
      timers: [...this.timers],
      updatedAt: this.updatedAt,
    }
  }
}
```
